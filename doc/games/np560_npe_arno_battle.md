## 实际使用流程

从原生第一槽恢复地图 3，世界坐标 `(1,25)`。通过普通矩阵键沿村庄道路前进，
在原出口 `(0,16)` 进入地图 10，落点 `(33,7)`，符合原出口记录。
之后沿树林道路行走，进入 mode 3 战斗；画面有两个敌人、角色及战斗控件。

- 选择攻击目标、确认后，角色与敌人均出现动作；结算后角色生命 `119→94`，真气仍为 `59/60`。
- 当时只读角色记录显示两个敌人均名为“弟子”，资源字段为 34；其中一个生命 `50→49`。
  这里只记录实际字段和画面，不凭角色名称推断图像正确，也未核对全部伤害/AI 公式。
- 实际打开战斗仙术入口，原厂提示“暂无修炼成仙术!”。F4 可关闭提示回到战斗。
  这不是模拟器已经施法；需要按正常剧情/成长取得技能后继续。
- 战斗旗帜图标打开“围攻 / 道具 / 防御 / 逃跑 / 状态”菜单。
  选择“逃跑”后原厂回到地图 10，世界 `(9,7)`，朝右。
- F4 → 系统 → 存储进度，选择此前为空的第二槽保存；原第一槽未覆盖。

角色战斗没有获胜，本轮没有验证胜利奖励、升级或装备效果；不能把动画和体力变化
等同于完整 NPE 战斗系统。场景仍使用与英雄相同的 RPG2.1 引擎。
