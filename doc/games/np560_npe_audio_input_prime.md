## 原规则与 C 接入

- 初始剩余长度大于 1024 时，设置 89.5、减去初始窗口的 1024 字节，再调用原生产者；生产者按请求位处理源 0 和源 1。
- 长度不超过 1024 时，清 89.14，尾指针设为 `0x8800 + remaining`，剩余长度清零，**不调用生产者**。该分支源码也不清原有 89.5；本轮动态样本的初始 89 为 0x4000，没有把已有 89.5 的情况计入动态证明。
- 初始输出长度为 `((samples << 2) & 0xFFFF) >> 1`，先发生 16 位左移回绕再右移。例如 160 得到 320，16384／32768 得到零，65535 得到 32766。
- 待接入源 0 数量转入可用数量，再清源 0 待接入数量；源 1 保留生产者结果。

`audio.c:npe_audio_input_prime()` 实现上述状态处理，保留 `initial_output_words` 元数据。`npe_audio_input_open()` 装载初始窗口后，向它提供当前候选的完整载荷长度，再由该服务统一扣除初始窗口。修复此前短段也调用生产者、额外设置 89.4 的行为。

当前候选载荷仍为资源长度减四字节头，包含交换所需的伴随字节。它不是原完整初始化通过播放范围偶数字节换算后的实际长度；当前字段读取和 SDL EOF 继续使用明确标注的候选帧数规则。此服务结束在 PCM 边界之前：原诊断边界返回后，输出长度为零会走原 FFFE 返回，但 C 不把这个后续返回当作初始化服务或实际 codec EOF 的证明。
