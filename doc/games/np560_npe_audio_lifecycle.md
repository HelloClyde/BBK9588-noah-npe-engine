## 原程序中的不同阶段

来源为原 `tmp/NP560.PRG`，SHA256 `d555609e03ece17f42c1881beeb88361572f18621161de67bc9dc765857089f5`。源码摘录 `tmp/npe-audio-lifecycle-original-source.asm` 中使用PRG源地址；下面同时说明运行地址。

- 游戏地图 `4E:A3F4..A484` 和战斗 `4F:649C..6506` 传入各自函数作为播放结束回调。`03:438C` 的跳转表进入 `32:5F86`，再经 `32:B974` 到 `25:0000`。它们重新打开资源，并非从PCM数组尾部直接跳回数组首部。
- `25:DF62`（源 `42:DF62`）初始化流并调用 `26:8D2A`。后者的原指令明确执行三次B7AA探测，计算码流位置、时长和请求范围。随后按范围重新初始化或恢复流，再建立输出。
- 实际补充PCM的 `2F:66F2`（源 `4C:66F2..6832`）调用 `2E:7FE4` 的两个半帧输出。完成后检查输出长度零，或压缩流当前指针**大于**有效尾指针，才置结束位 `BIT[89].11`；相等不走这条结束分支。不能只依据文件头count固定减一。
- `08:3B48` 检查结束位并进入 `08:39B6`，停止传输，然后经 `08:475E` 处理DAC。其它停止入口 `08:3262` 也使用这条DAC服务。
- `08:475E` 保存左右DAC word，调用 `08:3462`：共同目标零，等待参数 `0x005F`。收敛后关GPIO，再调用 `08:47A4`，参数 `0x0032`，最后关闭 `REG72` 的输出使能。`08:47A4` 使用Timer2与中断倒计时。已隔离执行原等待器确认名义1000Hz时基，并在SDL输出时钟上推进等待，不使用宿主sleep。
- 重启 `08:4702` 清DAC word、开启输出，按GPIO状态选择等待，再经 `08:33FA` 恢复保留的左右word。它与 `08:3536` 的八级PCM增益不是同一种渐变。

## 已移植的纯C数值服务

`audio.c` 的 `npe_audio_dac_ramp_step()` 对应 `08:33FA/3462` 的一次循环：

1. 对左声道作有符号比较，按目标加或减一；
2. 对右声道作相同处理；
3. 只有右声道发生写入时执行REP等待。右声道已经收敛、左声道还在变化时，原代码跳回比较，没有该等待；
4. 返回变化的声道及NOP数量。REP参数95对应96次NOP；保留的是原指令次数，尚不换算物理时间。

两路分别给目标即可覆盖启动函数；两目标相同覆盖停止函数。函数不分配资源，不依赖QEMU、Python、SDL回调长度或游戏编号。

**接线范围：** SDL已改为[从NPE逐帧候选解码](np560_npe_audio_stream.md)，每次重播初始化解码状态；尾部经过结束停止等待→重新打开前清理等待→启动等待。独立DAC逐单位数值服务尚未输出到SDL；已确认的等待阶段不包含渐变运算时间，不能据此宣称完整原循环渐变完成。

## Timer2服务链与SDL等待阶段补证

`tests/reference_audio_wait_chain.py` 保留原 `08:3262/3292/3906/4702/475E/47A4` 与 `24:9AB8/9BD4` 服务及其被调用函数，只新增外围诊断调用。低于20银行的代码走resident ROM；20及以上银行保留在PRG代码总线，避免误把高银行原函数映射成零填充。外围设置RAM向量、4MHz PLL、GPIO及驱动标志；没有NAND、codec或宿主客机内存写入。

使用同一Windows QEMU及instruction-clock。原Timer2 ISR实际倒计时、恢复中断配置；五条服务链均返回原栈位置，无缺失ROM／不支持指令。控制寄存器写入序列另逐项断言，第二次显式停止没有额外输出关闭操作或Timer2等待。

| 隔离调用顺序 | Timer2中断次数 | 诊断虚拟时间毫秒 |
| --- | ---: | ---: |
| 温启动 `4702` | 200 | 200.0395 |
| 替换活动播放 `3262→4702` | 250 | 250.274 |
| EOF／重开所用服务 `475E→3262→4702` | 300 | 300.2225 |
| 连续显式停止 `3262→3262` | 50 | 50.1485 |
| GPIO冷标志置位时 `4702` | 1200 | 1200.066 |

第三行按原 `39B6` 及重开入口中的调用次序隔离执行服务，**没有执行完整EOF中断回调、资源重开或codec**。表中的虚拟时间不是物理DAC测量；QEMU指令周期模型仍有未分类指令。

`sound_sdl.c` 将50／200个名义Timer2计数换算为32000Hz、单声道S16输出的3200／12800字节等待，跨回调保留剩余字节。自然EOF只停输出，保留驱动已配置状态；循环重开还需再次清理。有限播放EOF停后，下次显式请求也经过清理。显式停止完成后清配置标志，重复停止不再增加等待。等待不推进PCM游标或增益；重播阶段结束才将游标置零。主线程请求仍异步选定资源，等待由SDL回调推进；当前没有复刻固件请求期间阻塞主线程的时序。

独立C＋SDL程序没有原系统GPIO冷状态，因此只接温启动200计数，不默认增加1000计数。原 `BIT[8A].7` 全零音量的旁路及系统音量生命周期亦未接入；当前独立程序仍采用既有宿主可听音量7／7。
