# NPE 战斗攻防增益：独立计时、覆盖与倒地队员

2026-10-06。本轮修正 C11 + SDL2 的角色正攻防效果。
仙术／道具名称、数值和群体／阵营字段继续读取当前 NPE。
原厂运行时只用于独立参考采样；C 程序没有增加 WASM、Node 或 Python 依赖。

## 原厂规则与旧实现差异

原厂战斗记录有两个独立的**字**计时器：

| 运行时字 | 当前属性 | 基础属性 |
| --- | --- | --- |
| 6496 | 攻击 64B0 | 64AC |
| 6498 | 防御 64B2 | 64AE |

原 C 版共用 `battle_skill_turns`，用 `battle_skill_fresh` 延迟第一次递减，
另有防御动作计时。因此单个双属性增益的到期样本能通过，但交错使用只加攻击／
只加防御的道具时会错误清掉另一项增益，并把两项到期时间绑在一起。
这些临时字段已替换为 `battle_attack_turns`／`battle_defense_turns` 两个 16 位数组。
它们属于战斗临时状态，`NPESAV14` 存读布局不变。

正效果服务的 `2A:1D60..1FC4` 等分支只处理**有符号大于零**的对应效果字：

1. 当前属性写为基础属性加本次效果，保留低 16 位。
2. 对低字做有符号比较；大于 999 才写 999。
3. 对应计时字写 4；另一项数值和计时字不改。
4. 再次施放从基础属性重算，覆盖原增益并刷新对应计时，不叠加。

`38:F78C` 的下一轮准备遍历六个状态字，`FA68..FB5C` 处理计时递减，
`FB72..FC0A`／`FC0C..FCA4` 在各自计时为零时恢复各自基础属性。
施放本轮结束后计时为 3，再经历 2、1、0，恢复发生在下一次命令输入前。
不能将四种正状态免疫字也按这个规则递减；原厂对前四字另有门槛。

`2D:4F44..507A` 的防御动作写基础防御加 100，并将同一个防御计时字 `6498`
写为 2。它覆盖防御增益，但保留攻击增益及其计时；本轮结束后防御计时为 1。
只有攻击的效果也不会取消已有防御动作。

## 实际连续按键参考

使用原 NPE 道具 62／63、仙术 14“神龙附体”；这些 ID 只用于探针定位，
生产代码不依 ID 分派。仙术 42“鬼影身法”作为正常无即时攻防效果行动推进回合。
原始角色基础攻／防为 15／13，原始敌人 51 数据保持完整。

先用加攻击道具，下一轮用加防御道具的原厂结果为：

| 阶段 | 当前攻／防 | 攻／防计时 |
| --- | --- | --- |
| 入战 | 15／13 | 0／0 |
| 第一轮结束 | 115／13 | 3／0 |
| 第二轮结束 | 115／113 | 2／3 |
| 第三轮结束 | 115／113 | 1／2 |
| 第四轮结束 | 15／113 | 0／1 |
| 第五轮结束 | 15／13 | 0／0 |

三人同轮依次施放神龙附体、加攻击道具、加防御道具，三人最终为
115／113、计时 3／3，而不是累计 315／163，也不是只剩防御。

原厂还确认：

- 双属性增益后防御，攻击继续计时；只将防御写为 113、计时降为 1。
- 群体正攻防效果包含倒地队员，不复活、不增加其气。倒地前已有增益也继续计时。
  原 C 版“只写存活角色”的过滤已撤销。仙术与道具的倒地独立样本均通过。
- 基础值 950 加 100 得 999，不能仍把存储增益视为完整的 100。
- 基础值 32700 加 100 的低字为 32800，即有符号 −32736；原厂比较后保留该字，
  不改为 999。到期后恢复原始 32700。原 C 版每次读取属性时无条件夹至 999 已撤销。

以上边界比较的是原厂当前属性字，未据此声称所有负属性下的伤害、提示和动画已一致。

## 验证

- `buff-timers-probe`：十组原厂独立序列、**138 个队员状态**，逐项比较
  当前攻／防、独立计时、气、基础属性及倒地标记。
  包括交错道具、重复施放、正常到期、防御覆盖、三人同轮覆盖、999 上限、
  16 位回绕、增益后倒地、原先倒地的仙术／道具目标。
- `sdl-battle-item-flow-probe`：新增 **4 个多回合 SDL 序列**，实际按确认键进入
  道具／仙术页面并提交，与原厂状态表比较；连同原 15 个场景共 19 个。
- 构建、ctest 5/5、敌方规则、空道具 36 阶段、预扣 29 阶段、逃跑六组通过。
- SDL 攻击／投掷 10、仙术 7、围攻 3、逃跑 5 场景回归通过。
- 既有 **200 张整屏零差异**通过；本轮没有新增战斗状态页或动画像素验收。
- 连续 C 主线再次到 173、告别和标题。本轮为 **20 份角色属性诊断档**；
  原始属性前段仍到 10，野猪 9 次操作剩 56 体／6 气，花胶实际 15 份、425 次往返。
  当前规则改变了后段战斗与随机序列，所以诊断节点和数量不沿用上一轮 21 份。

SDL 攻击／投掷旧探针曾要求回合结束敌体必低于 500，但应用会在新游戏后使用
主机计数器重新播种，原厂野猪精可能施法补回上限。该断言已改为：若目标回到 500，
必须存在原 NPE 的正体力、友方阵营仙术且目标覆盖该敌槽；目标号、选择、预扣和数量
断言保留。类型 31 的 40／60 体效果已有独立睡眠隔离探针，不能为了测试删除敌方 AI。

原厂样本独立修改队伍、学术前缀、库存与属性，不作为连续剧情存档。
连续 C 路线仍只使用角色属性诊断，没有手改敌人、地图、NPC、背包、条件、进度或 NPE。
本轮未同步 C／原厂 RNG，因此不宣称每次受伤相同。
