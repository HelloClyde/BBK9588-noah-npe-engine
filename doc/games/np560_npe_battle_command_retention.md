# NP560 NPE：跨回合防御指令及回退前副本

## 已实现

原`64CF`指令字节现独立于宿主的待执行队列保存。下一回合保留防御5，其他指令清0；菜单复制的旧指令另存，不再从已经清空的宿主队列推断。

原源码`38:FD14..FD7A`检查`64CF==5`，命中则跳过清零。这是之前全部清队列时漏掉的行为。`2F:C93E..C95C`读取当前指令到菜单的`7AAE`；防御确认`42:8D32..8DA8`写指令5，再把菜单副本复制到`64D2`。

回退的顺序也必须保留：`36:DE84..DEA6`清被退回角色的当前指令，菜单全局旧指令保持。第二回合全员此前防御，先选防御、退回上一人时，原当前指令变0，当前菜单已保存的旧指令仍是5；重新选防御，类型副本仍为5。此样本无法证明副本来自被退回角色，后续仙术样本已纠正为当前全局值。

生产字段`battle_native_kinds[3]`保存当前指令，`battle_menu_previous_kind`保存单个全局旧指令（后续技能编号路径更正）。普通攻击、仙术、使用／投掷、围攻、联合攻击、失败逃跑的入口同步当前指令编号；原使用与投掷同为2，仙术1，联合3。入战和胜利清状态服务清这些字段；退出时原记录复制的完整布局仍待完成。

宿主待执行队列仍在回合末清空，两个驻留字段仅表示原选择器状态，不让上一回合动作重新排队。新增字段是运行状态，未改`NPESAV19`存档编码。
