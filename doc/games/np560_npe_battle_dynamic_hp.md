# NPE 排队目标变化与负体力群体受击

## 本轮结果

新增 **8 条完成的独立原厂输入序列、210 个完整角色／敌人记录阶段**。同一参考分别由 C 接口和实际 SDL 主循环核对，不把两次运行重复计算为原厂样本。游戏运行时仍为 C11 + SDL2，原厂前端只用于独立对照。

### 已排队敌方目标

先让主角对中间敌槽提交普通攻击，再把目标体力改为以下低字，同时让第一个敌槽变为正体力；另一名队员通过真实旗帜菜单防御，推动原命令执行。

| 目标执行前体力 | 原厂执行结果 |
| --- | --- |
| 0 | 重找第一个敌槽，体力 30000 → 29980；中间槽仍为 0 |
| -1（65535） | 保留中间目标，低字减 20 后限零；第一个敌槽仍为 30000 |
| -32768（32768） | 保留中间目标，低字减 20 回绕为 32748；第一个敌槽仍为 30000 |

这证实源 `40:176E` 的执行时重找目标只判断零，不能沿用普通目标选择的正体力门槛。

### 已排队友方目标

实际在原厂仙术列表选择技能 6，再选第二名队员；第二名队员已排队防御，改其体力后由第三名队员防御推动执行。

| 第二名队员执行前体力 | 原厂执行结果 |
| --- | --- |
| 0 | 治疗转到第三名队员，300 → 400 |
| -1（65535） | 保留原目标，治疗服务不写负体力 |
| -32768（32768） | 保留原目标，治疗服务不写负体力 |

三组均扣施法者 11 气（500 → 489）。变成非正体力的第二名队员跳过已排队防御，第三名队员的防御正常执行。技能、费用仍从当前 NPE 读取。

初次友方采样只提高了战斗区等级，未提高地图区等级，无法进入原厂技能列表；这三次失败不计完成样本。纠正独立夹具的地图等级后得到三条完整序列，原日志保留。

### 敌方群体伤害

两条独立夹具令三名队员体力为 `[30000, -1/-32768, 0]`，上限均为 30000。在独立原厂内存与 C 解析内存中，把技能 6 的效果设为体力 40、敌对群体，不修改磁盘 NPE。敌方按自身 AI 连续两轮普通攻击、第三轮施法；主角每轮通过旗帜菜单防御。

- 主角三轮体力依次为 29991、29981、29969；第三轮有效伤害为 12。
- 第二名队员 -1 减 12 后限零；-32768 减 12 保留低字，得到 **32756**，超过 30000 上限。
- 零体力队员仍为零；回绕为正值的队员不在同一轮补做行动。
- 每阶段对照体力、上限、气、属性、攻防、等级、经验、独立攻防计时及四状态；三轮 C 行动顺序均为主角、原中间敌槽。

队员普通选人要求正体力，群体服务仍遍历这些非正槽，两种门槛各自保留。控制种子 128 只用于复现这组敌方策略和浮动，不宣称还原原厂启动随机状态。

## 存档修复

原厂上述群体效果产生的体力 32756／上限 30000，C 可保存却被加载时的体力上限校验拒绝。本轮移除这个错误的体力关系校验，保留原始 16 位体力；气值、校验和、文件指纹、地图与队伍结构等现有检查保持。

存档字节布局仍为 **NPESAV15**。两条群体序列另从独立 C 世界副本实际逃离战斗，再保存／读取，完整保留三人的体力和上限。原厂夹具克隆主角记录，宿主 codec 副本采用 ID 1／2／3 满足现有队伍结构；不修改连续剧情档，也不宣称与原厂存档互通。

## 可复现入口

在项目根目录：

```powershell
& 'D:/Program Files/nodejs/node.exe' npe-sdl/tests/reference_queued_negative_hp.mjs
& 'D:/Program Files/nodejs/node.exe' npe-sdl/tests/reference_group_negative_hp.mjs 65535
& 'D:/Program Files/nodejs/node.exe' npe-sdl/tests/reference_group_negative_hp.mjs 32768
python npe-sdl/tests/generate_dynamic_hp_native.py
cmake --build npe-sdl/build --target sdl-dynamic-hp-probe -j 4
& npe-sdl/build/sdl-dynamic-hp-probe.exe tmp/tjfy-world-probe.npe
```

原厂脚本需要本地 `tmp/` 中既有 OpenNoah 适配器、WASM、原游戏包和入战快照。生成器优先读取完整六组排队输入；也支持已保留的首次敌方成功记录及修正后的友方成功记录。群体脚本仅修改 resident NPE 副本；C 夹具在释放资源前恢复被修改字节并核对原文件指纹。

本轮构建、ctest 5/5、既有负体力／属性／普通攻防／气值、状态道具／复合效果、敌方行动、离场、增益、空道具及相关 SDL 回归通过；旧参考画面通过。连续 C 主线仍以 **20 份角色属性诊断档**到 173、告别和标题，材料 15 份／369 次往返，未增加剧情节点或整屏参考，整屏参考累计仍 **317 张**。
