## 敌方目标页

原厂隔离参考直接显示：

- 从列表进入单体敌方仙术选择时，首先选中第一个存活敌槽。
- 黑色向下指针为 NPE 战斗资源零基 **5**，放在敌图 `(x+16,y-4)`。
- 行动队员的向上指针仍在；体／气显示施法队员数值；仙术图标仍被选中。
- Down 向后扫描，Up 向前扫描，跳过空槽／倒地敌槽并循环。
- Left、Right 与 Cancel（在线输入掩码 32）不改变此目标页；Menu（64，原机 F4）返回列表。
- 移动只清除旧指针矩形，再画新指针。清除边界包含 `y+4`，横向左边界按四像素对齐；
  因此从中间野猪头上移走会擦掉该敌图第一行的四个像素。全场重绘会抹去这一原厂结果，不能用来代替。

C `npe_render_battle_enemy_target`／`npe_update_battle_enemy_target` 和 SDL
`show_battle_skill` 现按上述画面与输入操作。首次目标重选第一个存活敌人，后续保持局部绘制缓冲。

## 内力不足提示

原版提示为 **「内力不足!」**，不是原 C 战斗路径使用的「魔法值不足!」。
底下保留当前仙术列表、人物肖像、费用／当前内力和说明，不进入地图角色属性页。

确认技能时先检查施法者内力，内力不足不会进入单体目标选择、排队行动、扣内力或执行敌方回应。
提示边框为 `x=80..160,y=49..71`，灰底色阶 5，原厂 16×16 字体起点 `(84,52)`；
外侧清除区域为 `x=79..161,y=48..72`。

原厂采样结果：

| 输入 | 可见结果／菜单值 |
| --- | --- |
| 在列表确认缺少内力的技能 | 列表上显示提示，菜单值 21 |
| 再按确认 | 同一提示画面仍在，内力与体力不变 |
| Cancel，掩码 32 | 只关闭提示，恢复完全相同的列表，菜单值 21 |
| 提示期间 Menu，掩码 64 | 关闭提示并离开列表到仙术图标，菜单值 20 |
| 再按 Menu | 回默认攻击图标，菜单值 10 |

SDL Escape 对应此次 Cancel 路径，F4／Backspace 对应 Menu 路径。
提示背景保存为列表缓冲，取消后恢复原图，避免滚动列表局部清除的结果丢失。
地图仙术页面现有提示路径未在此次改动范围内，不能由此推断其文字或输入已经验收。
