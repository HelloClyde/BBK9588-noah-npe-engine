# 入战、胜负／逃跑离场与再次入战的资源流程

更新：2026-10-09。生产实现为C11／SDL2；原固件和参考前端仅用于开发对照。

## 实现

资源操作统一由 `npe_world_battle_resources` 执行，菜单和数字战斗规则共用。实际资源运行时使用原C堆服务和当前NPE的第9段；未附着资源运行时的规则调用同步World标志。

| 原调用点 | 已接入的行为 |
| --- | --- |
| 普通入战4E:7F30..7F70 | 分配32768字节、锁定、发布句柄／指针，写高字节1并读取打包图像 |
| 剧情入战4E:8B80..8BC0 | 同上；追击也接入普通入口的资源流程 |
| 战败33:BCA2..BCCA | 进入阶段59后，离场画面前无条件解锁／释放，清高字节 |
| 胜利33:C23E..C266 | 道具返还后、奖励显示前解锁／释放，清高字节 |
| 成功逃跑2F:C0DC..C104 | 逃跑人物绘制后解锁／释放，回地图时高字节为0 |

原解锁和释放分别重读52:7A88，保持释放后的句柄／指针；52:7AA5低字节保留。再次入战重新分配和读取，不依赖释放后残留的数据。

地图／标题World的资源构造不再提前占用一块战斗缓冲，避免首次入战再分配32KiB时重复占用。新 `npe_rpg_runtime_open_idle` 保留启动所需的其它资源初始化，待入战装载打包资源。战斗World或明确保留有效缓冲的World仍使用装载构造；资源查看器和原服务专项检查保留原 `npe_rpg_runtime_open` 行为。

没有新增World绑定，仍3536字节；save.c与NPESAV22保持。地图新构造的资源标志为0，四种暖恢复的129／166字节保留及自身存档检查继续通过。
