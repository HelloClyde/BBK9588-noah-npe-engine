## 各分支的体力门槛

体力字的比较方式由各自的原指令决定，不能统一替换成一个“存活”判断。

| 分支 | 原厂源地址 | 规则 |
| --- | --- | --- |
| 命令角色、速度调度 | `39:5940..59C2`、`2F:CA8C..CB2E` | 带符号体力大于零，并检查眠／乱 |
| 敌方 AI 是否可开始 | `32:D474..D53A` | 至少一名队员带符号体力大于零；否则不抽策略／目标随机数 |
| 敌方普通选人 | `32:E13A..E13C` | 初选非正体力时顺序扫描，不重抽随机数 |
| 普通攻击选敌与自动提交计数 | `40:1944..1946`、`40:1BDE..1BE0` | 只包含带符号正体力敌人 |
| 已排队动作的目标重找 | `40:176C..176E` | 只检查零；负值保留为原目标 |
| 全队败战／全敌胜利检查 | `33:BF92..C114` | 检查整侧体力是否全为零；负值不是零 |
| 发经验、升级 | `44:6D16..6D18`、`2F:A536..A538` | 负值与零都跳过 |

C 修正了敌方目标扫描、选敌正值计数和经验／升级门槛。侧退出及排队执行的零判断继续按原厂保留。全部体力非正且仍有负字时，不将其自定义为败战，也不在 C 的“等待眠／乱恢复”循环里永久阻塞；该异常场景的完整原厂菜单时序仍待验证。

## 扣体力与低字回绕

源 `2A:107A..1166` 对敌人采用带符号正效果门槛，先减并保留低字，再把负结果写零。敌方攻击队员的 `2A:26BA..2752`／`2B10..2BA8` 同样先减低字，再对非正结果写零。因此直接比较无符号伤害与无符号体力不适用于负体力或回绕。

C 的普通敌人体力扣除和敌方攻击扣除改用低字减法。零或负待结算量仍不写体力，不自行回血。独立完整战斗输入目前证明普通正目标及负槽保留；已排队目标变负、负体力群体受击的更多动态原厂输入仍待完成，不能把本轮采样称为全部扣体边界验收。

## 胜利后的体力公式

胜利源 `33:C27E..C298` 依次发经验、掉落、升级、重置状态，之后逐个处理体力：

- `C2E4..C328`：带符号体力非正的队员恢复为 1，已经错过的经验和升级不补领。
- `C32E..C3E8`：原先体力为正的队员，分别计算带符号 `最大体力 / 10` 和 `64A6 / (64A6 + 20)`，商向零截断，两个商相乘保留低字后加到体力。
- `C456..C4B4`：只按带符号比较限制最大值，不再次给负结果补 1 或限制到零。

第二项整数除法在常规正属性下得到零；必须保留原运算顺序。C 原先漏了这段公式，现已接入。除法异常使用与[属性倍率](np560_npe_battle_attribute_multiplier.md)相同的 DMCU 寄存器保留语义；本轮原厂完整战斗没有覆盖除数为零。

原厂参考确认：

| 胜利前体力／最大体力／64A6 | 胜利后 |
| --- | --- |
| -1 或 -32768／30000／1 | 体力 1、经验 100 保持 |
| 30000／30000／1，存活队员 | 体力 30000、经验 100→145 |
| 100／1000／100 | 体力 100 |
| 100／1000／-100 | 体力 200 |
| 100／1000／-19 | 体力 -1800（低字 63736），没有再补为 1 |
| 990／1000／-100 | 体力封顶 1000 |
| 100／-32768／-100 | 体力 -32768，保留带符号最大值比较 |

另从 `39:41D4..4218` 核对掉落属性求和只遍历队伍起始的正体力连续段，遇到第一个非正值即停止；之前“遍历全部存活角色”的说明撤销。此修正依据源指令，完整掉落提示与随机阶段仍待原厂画面核对。

## 采样与 C／SDL 对照

`reference_negative_hp.mjs` 克隆三名参战记录，在独立 RAM 设置体力、攻防、等级及经验，实际按键完成行动。初次两个负敌槽探索输入发送了额外方向键，跨动作阶段，未纳入单回合参考；原日志保留。其余十条分别验证三组敌方跳过负体力队员，以及七组胜利结算。

`reference_negative_hp_picker.mjs` 的四条补充输入验证：

- 负敌槽为 -1／-32768，另仅一正敌时，原厂菜单保持 10，直接攻击中间正敌。
- 有两名正敌及一个负槽时，菜单为 17，目标序列 `5→6→5→6`；循环始终跳过负槽，确认攻击第三物理槽。
- 负敌槽保留原字，不行动；这不等于已经胜利，也不伪造其死亡。

共 **14 条完成的原厂输入／168 个完整记录阶段**。参考包括六个战斗记录的体、上限、气、64A6、当前攻防、等级、经验、两项计时及四状态。C 行动和实际 SDL 主循环分别与同一参考核对，不重复计数。控制种子 4／381 只复现参考浮动，不宣称还原启动 RNG。
