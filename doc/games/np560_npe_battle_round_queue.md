## C 与 SDL 当前实现

所有可行动队员先选择指令。选择阶段不扣体力、气或道具，也不抽战斗随机数。
随后反复选择未行动的最高速存活角色或敌人。指令保留原选目标，执行时原目标
已经倒下则向后扫描并绕回。角色在轮到它之前倒下，其普通指令不执行、道具不消耗。
围攻为多名可行动队员赋共同目标，进入相同队列。

队列、资源指针和顺序诊断字段仅用于当前战斗；C 存档仍只允许地图模式，
不更改 `NPESAV14` 格式。数值仍在一次 C 调用内结算；[围攻逐人动画](np560_npe_battle_group_animation.md)已由显示回调逐阶段提交，六组 153 次画面与原厂一致。敌方和其它动作的完整动画、真实等待单位及声音仍未完成。

验证覆盖：速度排序、同速顺序、睡眠／封印排除；真实 NPE 的指令延迟扣费；
高速敌人击倒持道具指令者后保留道具及精确 RNG；两人同选已倒下目标后的绕回；
两人普攻的精确随机状态；SDL 单人单敌／双敌和双人围攻菜单按键。

新版调度的真实 NPE 连续剧情探针仍从新游戏到告别、37 帧结尾及标题，
累计 **21 份角色属性诊断档**。后续修正全部行动准备 RNG 和敌方普通公式，
本次重试位置变为蛇妖及万王洞第一阶段等，仍为 21 份；旧第二场石像战
重试记录只描述前一版本路线。诊断只改角色属性，战前检查点
的地图、NPC、物品、条件、进度和事件链保留。这不算原始属性通关。
