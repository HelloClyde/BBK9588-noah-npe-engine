# NP560 NPE：独立技能编号和菜单全局旧指令

## 生产实现

新增`battle_skill_ids[3]`对应原`64D6`。技能确认进入目标页即写入，取消目标、退出列表、改选道具或防御、回退、下一回合均保留；再选另一技能时替换。入战及胜利清状态服务清0。技能执行装载和只读动画视图以独立编号为准，不从宿主命令资源字段推断。

原写入见`3A:0A92..0AB6`，执行读取和共享技能装载见`2D:3CD0..3CEC`，胜利清零见`38:E4BA..E4DC`。回合重设保留此字段。道具确认`38:49DA..49FC`会清`64D0`，但保留`64D6`；生产中已有`battle_magic_types`同步此清零，入战和胜利也清原技能类型及相关准备字段。

新增字段为运行状态，不写入NPESAV19；原机存档互通已按用户要求取消。保留本程序存读档，不把互通作为待办或完成门槛。

## 更正上一轮菜单副本模型

原`7AAE`是一个全局字节，`2F:C93E..C95C`在正常进入当前角色菜单时保存旧指令。回退`36:DE84..DEA6`清被退回角色的`64CF`，不重取该角色旧指令来替换`7AAE`。

上一轮用每角色数组保存副本，连续防御样本中各角色旧值都为5，无法区分这个错误。新增`replace-back`中，角色0的指令为仙术1，进入角色1菜单时旧指令为0；回退角色0后再防御，原副本为0。旧C错误写1。

现改为标量`battle_menu_previous_kind`：正常换角色和回合菜单入口取新角色的原指令；回退沿用当前全局旧值。取消选择返回基本菜单的服务更新沿用当前已选择的指令。全部已有回退与连续防御路径通过。本轮比较实际后续类型副本和驻留记录；没有宣称全局字节在每个内部菜单瞬间均已采样核对。
