# 战斗动作声音选择与当前 NPE 范围播放

更新：2026-10-09。本批实现纯 C 的原版声音选择服务，并接入战斗执行和 SDL 的候选解码播放。原声音解码、完整文件服务与物理 IRQ／DAC 时序仍未完成。

## 原版规则

原函数为 `3E:F85E..FD7E`，普通执行器在 `39:5D7C` 调用，位于敌人 AI／目标准备之后、行动动画之前。独立 QEMU 采样执行未修改的函数；只把 `03:438C` 播放入口替换为参数记录边界，不执行原文件打开、解码或 DAC。

| 分支 | 声音来源 |
| --- | --- |
| 我方原指令0，普通攻击 | 当前物理人物记录114..121中的偏移／长度 |
| 原指令1，仙术；目标属于我方前缀 | `7952/7956`，当前 NPE 段35 |
| 原指令1；目标超过我方前缀 | `794A/794E`，段30 |
| 原指令2，道具；目标属于我方前缀 | `7952/7956`，段35 |
| 原指令2；目标超过我方前缀 | `796A/796E`，段32 |
| 原指令3，联合 | `794A/794E`，段30 |
| 原指令4／5及其它值 | 不产生动作声音请求 |
| 敌人行动；目标属于我方前缀，目标的原指令为5 | `7972/7976`，段31 |
| 其它敌人目标 | 不产生动作声音请求 |

`52:7A50` 是完整16位声音开关。值0直接返回并保留 `7A98`；其它值先清 `7A98`，选中声音后写1，最后仅在开关恰好为1时请求播放。不会把 `0101` 截断为1。

声音偏移保留完整32位；长度只取描述中的低16位，再有符号扩展到32位。0、7FFF、8000和FFFF按原规则传到播放边界，C选择器不会提前改写。文件指针是原当前 NPE 名称 `52:6EBA`，其它三个32位参数为0。

零执行索引按 `index-1` 读取前一记录地址，不自动改成首角色。255索引同样保留原地址运算；本批只证明对应选择服务片段，不证明异常人数的完整战斗。

## 生产接入

- `battle_sound.inc`：纯 C 原声音选择服务，共用既有客机RAM读写接口；`7A98`留在持久资源运行时中，没有新增独立 World 副本。
- `rpg_runtime.inc`：装入原目录30..37的八组声音描述，保留原地址分布；读取实时物理记录与实时缓存，不按角色名或游戏名选声音。
- `resident_resources.inc`／`npe.h`：把完整 `7A50` word 接入 World／运行时的双向读写。World绑定由3545增至3547字节。
- `world.c`：普通我方行动在目标解析后、动画前请求；敌人行动在 AI 目标写入后请求。围攻使用原指令4，所以不会被普通攻击动画类型误判为人物攻击音效。
- `sound_sdl.c`：新增偏移／长度请求，借用当前 NPE 的压缩数据。单独保留当前范围，重置解码历史和播放状态；没有循环回调的动作请求按有限声音播放。人物记录描述被修改后，下一次请求读取修改后的范围。
- `save.c`／暖重开：保留范围观察回调；原自身 NPESAV22 序列化载荷未扩展。资源运行时RAM本身仍不作为原机存档实现。

宿主范围验证目前只支持既有格式13声音；越界、负长度、不匹配的流长度会停止候选播放，不替换成其它声音。这是宿主验证策略，不能据此声称原文件失败／异常负长度播放行为已经复刻。

## 验证

报告：`tmp/battle-sound-report.json`。

1. `reference_battle_sound.py`：33组原函数执行，包含指令0..6／255、友方／敌方目标、声音开关0／2／0100／0101／FFFF、长度符号边界、敌人目标的防御分支、零与255物理索引。记录全部12个播放参数word；栈恢复，原函数字节一致，无缺失ROM或不支持指令。所有初始化写入均由客机指令完成。
2. `battle_sound_probe.c`：同33组输入的纯 C 选择器与原版完整128KiB RAM、播放参数及标志一致；33组生产资源运行时选择结果一致。启动后的八组声音目录与原始 NPE 对照通过，完整音乐word双向／逐字节读写通过。
3. `reference_battle_sound_resources.mjs`：独立原版已加载游戏快照中，目录30..37的八组偏移／长度与当前 NPE 一致。未修改原快照、固件或NPE。
4. `sdl_battle_sound_probe.c`：六个声音段的范围请求与原段请求输出的第一个160样本候选PCM帧一致；额外验证不在目录中的有效压缩范围、实时人物描述改写、负长度／越界／错长度停止，以及普通攻击的声音请求发生在动画前。它没有与原声PCM比较。
5. 38项必要短检查、39目标构建无警告；包括普通攻击／围攻／联合、敌方普通攻击和各类仙术、我方仙术／使用／投掷、共享执行记录、连续战斗、入战离场、失败逃跑、共享RAM和自身存读档。补充目录断言后只重建／重跑声音选择探针，未重复整批回归。
6. 前批1460份证据及八份原文件／字库哈希保持；本批构建与探针初期错误日志保留。采样初始化修正了8000以上地址的半页选择，最终33组使用修正后的客机初始化，原选择函数保持。
