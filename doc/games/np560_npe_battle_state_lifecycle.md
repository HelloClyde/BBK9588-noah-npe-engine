## 实现与验证

- 三种入口（剧情、随机、追击）重新读取装备并更新地图状态。
- 胜利清零战斗效果后回写四状态；成功逃跑／战败保留战斗效果后回写。
- 仅覆盖参战地图记录；未参战记录保持原值。
- 倒地胜利恢复到 1 体放在奖励、升级之后。
- `generate_battle_lifecycle_native.py` 从八份独立原厂 JSON 生成 C 期望；
  `battle-lifecycle-probe` 对照入战、离场共 32 个队员阶段的四状态，
  离场两项计时、倒地胜利及未参战记录均通过。
- 每组离场状态另复制为独立地图模式夹具，验证 NPESAV15 保存／读回四字。
  宿主只允许地图存档；这不代表胜利对白或标题页可直接存档。
- `enemy-action-probe` 检查装备在三个入口重建及非胜利低字状态回写。
- 构建、ctest 5/5、地图规则／装备属性、战斗增益 138 状态、空道具 36 阶段、
  逃跑规则、SDL 逃跑五场景及地图仙术九场景回归通过。
- 连续 C 主线再次到进度 173、告别和标题，仍为 20 份角色属性诊断档。
  原值野猪精仍为九次操作、剩 56 体／6 气；花胶 15 份、424 次材料往返。
  未手改地图、NPC、敌人、物品、条件或剧情进度。
