# 战斗状态道具：固定三槽、低字相加及封术入口

2026-10-06。C11 + SDL2 已将战斗类型 2 道具与仙术共用原厂四字状态服务。
状态值和群体／阵营标记读取当前 NPE；没有按道具 ID 固定规则。

## 原厂作用范围

道具状态文件字 +29／+31／+27／+33 装入 `7420..7426`，
按原厂战斗记录的 `648E..6494` 顺序相加。使用与投掷按阵营分别选择记录起点。
单体服务 `2D:4BFA..4CAE` 处理选定记录的四字。
群体服务 `2D:4744..4A04` 固定遍历**三个连续物理记录**，不使用实际人数作循环上限。
仙术 `2D:3F2C..414A` 使用相同的三记录范围。

| 群体方向 | 原厂三个记录 |
| --- | --- |
| 己方，一人队伍 | 队员 0、敌方槽 0、敌方槽 1 |
| 己方，两人队伍 | 队员 0、队员 1、敌方槽 0 |
| 己方，三人队伍 | 三名队员 |
| 敌方 | 敌方槽 0、1、2，包含倒地和未装载的空槽 |

C 的队员数组允许非紧凑活动位置，服务先按活动顺序映射为原厂紧凑记录。
四字相加保留低 16 位，负字段也参与，重复使用叠加；此处没有正值效果门槛或免疫拦截。
这是状态路径，不能套用战斗体／气／攻防标量的规则。

下一轮准备中，活动队员的负状态向零推进，包含倒地队员。
敌方仅对当前体为有符号正值的记录推进，倒地／空槽的负状态保持原值。
原剧情战的中间敌槽眠免疫会在此后重新写 10，**即使该槽没有敌人**。
因此群体效果写入眠字后，下一次菜单观察的中间槽值可能已被覆盖。
本轮使用独立空槽夹具核对写入与下一轮更新；没有把空槽当作活动敌人调度。

## 第四状态与仙术选择

原厂输入服务 `4E:06D2..06F0` 检查当前角色 `6494`：
负值时 Confirm 保持仙术图标菜单 20，不打开列表，也不显示新增提示。
气、体、记录状态和选定命令不变；零值和正值打开列表 21。
原 C／SDL 缺少此入口门槛，现已修正。

这是选择入口检查。已经选好、在本轮执行中才被封的仙术仍执行；
原厂二人序列确认先使用群体负第四状态道具、后执行已选仙术 42，第二队员仍扣 25 气。
C API 在选择阶段返回 -5，SDL 保持原画面；执行已排队命令不额外应用该门槛。
原敌方 AI 的第四状态门槛此前已实现，本轮没有改变其随机数消耗或策略。

## 2026-10-06 追加：排队动作、失能推进与中毒门槛

新增五条原厂按键序列，共 **72 个完整物理记录阶段**；含三人群体乱、三人群体眠、群体毒＋乱、
三人中第二人单体乱、单体毒＋乱。四字效果仍在独立常驻 NPE 副本的类型 2 道具中改写，
原磁盘 NPE／PRG 和连续剧情存档保持不变。两条毒样本在 RAM 中将首敌等级设为 10，
避免用复制空记录的零等级推断中毒规则。

原厂调度 `39:5936..59EA` 每次选择行动前重新检查体力、眠／乱，
因此施加负乱／眠后，被影响队员此前排队的仙术不会执行，气保持 500；
两项与第四字封术不同，第四字不阻断已排队的仙术。

| 序列 | 原厂结果 |
| --- | --- |
| 群体乱／眠 -5 | 首位用道具后，第二／三位仙术跳过，三人气均 500；计时自动五轮恢复零，敌乱 -36→-31 |
| 群体毒＋乱 -5 | 三人体保持 500；失能回合只推进计时，毒最终归零 |
| 第二位单体乱 | 第二位气保持 500；第三位正常施法气 500→475→450；乱 -5→-4→-3 |
| 第二位单体毒＋乱 | 第二位气保持 500，体 500→480→460；第三位正常行动使中毒门槛成立 |

中毒服务不是每个计时回合固定调用：`39:605C` 在实际行动后调用，
`36:6FFE..708C` 还要求全部行动标志就绪。群体失能样本首位行动后第二／三位尚未标记，
下一轮扫描虽把他们标记，却没有后续实际动作，因而不会扣中毒体力。
单体失能样本仍有第三位实际行动，最后一次行动后标志就绪，按首敌等级 10 扣 20 体。
C 既有调度与这五条原厂记录一致，未改成恢复后继续执行此前取消的命令。

`status-items-probe` 与 `sdl-status-items-probe` 均扩至 **20 条原厂序列、272 个完整记录阶段**；
每阶段新增命令角色对照。SDL 用实际道具列表及 Up 选中三人中的第二位，再提交仙术命令；
队员和敌人目标分别按原厂方向导航。五条新增序列均走 SDL 输入，不属于辅助防御 API 验收。
