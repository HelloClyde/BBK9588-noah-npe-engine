# 战斗“查看状态”原版界面

更新于2026-10-09。接续[战斗菜单阶段](np560_npe_battle_phase_resident.md)，用C11与SDL2替换旗帜菜单的宿主信息弹窗，按原版阶段35显示人物战斗属性。游戏图像、肖像和UI底图从当前NPE读取，中文文字使用原字库；原PRG与WASM仅用于独立参照。

生产`npe_render_native_battle_member_view`从战斗记录取姓名、头像、等级、经验、体力、气和状态；攻防读96／98字节的战斗有效值。复用原属性页绘图时只修改临时视图，保持地图记录和战斗记录不变。

当前行动角色与状态页选人值相互独立。三人参照特意设行动角色1、保留选人2：首次显示角色1，下键依据保留值2回绕到0。C遵循同一规则，不把首次显示的角色号写回选人字节。

返回旗帜菜单的六次提交依次为人物平面、HUD、角色光标、负数状态字、按钮、旗帜列表。首次返回曾少两个状态标记，共154像素差异；原因是普通回合刷新标志限制了显式返回刷新。现将显式刷新与原有条件覆盖入口分开，保持普通回合调用条件。

SDL主循环在阶段35空闲等待时保留LCD；否则外层循环会把战斗按钮重画在状态页上。实际main专项包含状态页可见时一次返回0的等待观察，验证没有额外画面提交。

## 对照范围

四条原公共输入短路径覆盖单人、两人、三人及三人保留不同选人字节。原版入战后修改战斗属性，使其与地图属性不同，并包含倒下队员、正负状态字和基础／有效攻防不同；随后打开旗帜列表进入状态页。

每条路径12次输入，包括首次进入、上下切人、无效左右／确认、取消、重开和再次切人。单人14次LCD提交，其余各19次。直接C／SDL与实际main／SDL各71次，共142次，逐像素对照原版240×120画面；检查也读取实际SDL输出色值。

两路线每步保存阶段、行动角色、选人字节、列表行，以及三份地图／六份战斗记录。每路48份控制状态、432份完整148字节记录，共96份控制状态及864份记录与原版一致。夹具只使用原入战和输入前记录，没有把原结束状态预置到C。

原四种暖恢复入口（运行中读档、标题读档、重新开始、空槽开始）在7AAC／7AC8写129／166后均保留。C的运行时地址接口、World和暖恢复一致；冷读取选人初值0。自身NPESAV22格式保持，四对保存副本逐字节一致。World绑定增至3534字节。

## 回归修复

两项旧状态覆盖检查共用`status_overlay_probe.c`，首例各2775像素差异。原夹具在入战后才扩展队伍，物理前缀与坐标仍属于原人数；同时只把敌人查询ID改为51，没有同步物理记录的图像word。
