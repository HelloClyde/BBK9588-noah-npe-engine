# NPE 战斗道具列表、预扣与友方目标

2026-10-06。运行时为 C11 + SDL2，资源和效果参数读取当前 NPE。
原厂 WASM 仅用于离线证据采样，C 程序运行不依赖它。

## 原始记录和固件入口

原厂 `3F:C370..C846` 装载道具。字段位置不能套用仙术记录：

| NPE 字节 | 固件暂存 | 当前解释 |
| --- | --- | --- |
| +12 | 7428 | 效果类型 |
| +13 / +15 | 7410 / 7412 | 体／气效果字 |
| +17 / +19 | 7414 / 7416 | 攻／防效果字 |
| +27 | 7424 | 封状态字 |
| +29 | 7420 | 中毒状态字 |
| +31 | 7422 | 眠状态字 |
| +33 | 7426 | 第四状态字，含义待继续追踪 |
| +35 | 7429 | 原始标记，含义尚未确定 |
| +36 | 742A | 群体标记 |
| +37 | 742B | 阵营：0 敌方、1 友方、2 拒绝使用／投掷 |

撤销“+35 是使用场合”的未经证实解释。原 parser 把 +33 当封状态也已修正。
`NpeItem` 保留四个有符号状态字。仙术的群体／阵营在 +37／+38，不能混用。

`4D:1FBE..20CE` 列出背包 ID 1～254 中数量为**有符号正数**的道具。
“使用”和“投掷”显示相同列表，不按类型 31 或阵营预先筛掉道具。
`38:47E0..4850` 在确认后检查阵营；群体复活的全队存活拒绝门槛在 `38:47C4`。
拒绝保留数量、选中项和列表，显示原厂“不能使用!”／“不能投掷!”。
两串文字来自固件 `4E:DBE6 / DBDC`，其存储按字交换字节；它们不是游戏文案。
提示等待按原厂调用的 2000 ms 实现，完整输入／逻辑 tick 时序尚未逐帧验收。

## 预扣、选人和队列

`38:4D56..4DB6` 在进入目标页**之前**扣一件。道具命令均为原厂 action 2。
原厂样本 `native-use-2-46-cancel.json` 中，1→0→F4 退至 1，重选又为 0，
再次 F4 回到 1。C 使用与投掷共享预留、取消、退上一人、覆盖和执行清理。
执行前倒地不退回道具。旧世界探针的“执行时才扣药”断言已经撤销。

`38:4E3E..4F4E` 决定是否选人：群体自动提交；单队员自动提交；
多队员的单体友方道具进入菜单 37，即使仅一人存活。

- 首选**当前行动队员**，不是固定第一人。
- Up 加一、Down 减一，在原厂紧凑队伍中循环，包含倒地队员。
- Left／Right／Cancel 不改变目标；F4 取消并返还道具，返回原列表选中项。
- 友方选中图使用当前 NPE 灰指针，体／气显示被选队员，旗帜图标保持选中。
- 普通药品选到倒地队员仍可排队，结算按 `40:153A..176E` 向后扫描存活者。
  类型 16～19 复活不做这个替换，只恢复倒地者，存活队员的体／气不变。

原厂三人夹具最初是在入战画面生成后才把第三人体力改为 0，造成缓存站立图。
现已改为在原厂入战之前设地图角色体力为 0，再生成战斗画面；未为迎合旧夹具修改 C 倒地图。

撤销旧毒飞刀额外中毒／毒伤断言；原厂两组独立投掷确认敌体 500→460／440，状态不变。
复活、正状态免疫和负状态向零推进接原有共同回合服务。
后续已撤销共用攻防计时和存活过滤：己方正效果按两个独立字执行覆盖／刷新／到期，包含倒地队员，并按有符号低字限制上限。十组原厂序列 138 个状态及四个多回合 SDL 序列通过，见[独立计时验证](np560_npe_battle_buff_timers.md)。敌方／负值及复合效果仍待完成。
