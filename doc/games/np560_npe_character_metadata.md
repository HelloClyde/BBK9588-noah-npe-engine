## 原执行对照

原侧使用离线 `certified_original_v1` 引擎、当前天降 NPE／NP560 PRG 和独立暖战斗快照。诊断只改隔离 RAM，未改原磁盘 NPE／PRG／快照或原随机服务；参考脚本及生成夹具在 `npe-sdl/tests`。

- 三条地图→入战→战中修改→原按键逃跑→再入战路径：单人、三人、中间空位及人物 ID 倒序。地图与战斗性别、八图号和三动画字段一致；三人例另执行原模式 10 离队交换，字段随 ID 移动。入战 12 次完整 240×120 提交，C 像素与实际 SDL RGB 读回零差异。
- 两条战中施法编号修改路径：人物仍为一号，NPE／地图施法编号保持 2／3，独立战斗副本改为 7／2。原敌方伤害与友方回复路径共 60 次提交，C 与实际 SDL 零差异，84 个全体记录阶段一致。覆盖生产动画与实际主程序按键流程。
- 两条战中逃跑编号修改路径：一号人物战斗编号 10→11、二号人物 11→10，NPE／地图初始副本保持原值。单人／三人逃跑及返回地图共 34 次完整提交，C 与实际 SDL 零差异。
- 地图性别 0／1／2／3 配合两种装备限制的八组 C 服务检查，按原反汇编分支拒绝／允许。这里不是新增八条原输入截图路径。

## 自身存档 NPESAV20

在 V19 的完整 payload 后追加 **60 字节**：每人性别 1 字节、八图号 16 字节（宿主存档小端）、三动画编号 3 字节；逐字段编码，不保存 C 结构填充。地图群攻继续使用 V19 的 GP 扩展，独立战斗副本不进入文件。

读取 V1～V19 保持原迁移规则；缺失人物元数据时，按保存人物 ID 从当前 NPE 补建。V19／GP 群攻可保留，旧 V19 零保留字节及 V18／更早档按正确 NPE 字节 79 补群攻。新格式要求本版程序读取，旧构建不支持 V20。

新增四组保存序列覆盖冷读取、暖恢复、地图字段／战斗副本隔离、V19 补值、换人后读取、暖新游戏重置以及截短／多余尾字节的失败事务。既有问答短探针继续逐个检查 V1～V18 前缀；群攻旧 V19／V18 迁移、NPC 位置有效位、同伴方向和 53 个地形槽的旧档迁移保持。

原机存档互通、正常属性完整通关和 SDL 全程实玩均已取消；本轮未恢复这些要求，未重跑长剧情路线或全套 ctest。
