## 更新与接触

runtime `1D:5820` 对应 source `3A:5820..5F56`。原始 `NP560.PRG` 此范围与此前诊断 PRG 一致，范围 SHA-256 为 `ab0560d0a0c4ac2879d825f8466459800db70f24bf95f16a888880e3ed12f98b`。

每条有效记录先检查冷却；大于零则减一并退出整个函数。否则计算有符号坐标：

```c
cx = chase_x - scroll_x - 1;
cy = chase_y - scroll_y - 1;
hx = hero_screen_x;
hy = hero_screen_y;
```

接触分支在 `3A:5AAE..5B58`，按实际跳转为：

```c
(cx == hx - 2 && cy >= hy - 2 && cy <= hy + 2) ||
(cx == hx + 1 && cy >= hy - 2 && cy <= hy + 2) ||
(cx == hx && (cy >= hy - 1 || cx <= hy + 1))
```

第三支在 `5B48` 是 `SGE -> 5B5C`，可直接接触；未跳转才在 `5B56` 用 R0（仍为 cx）比较 `hy+1`。不能改写成普通矩形的上下界 AND 条件。测试覆盖远在主角下方、同 X 分支仍进入战斗的情况。

无接触时，`3A:5BB0..5D66` 按 cx/hx、cy/hy 分别向主角移动一格；两轴可以同时变化，不查询墙体、固定 NPC 或出口。接触在本次追击移动之前判断。

`37:18CE` 在普通移动或受阻尝试后、没有进入随机战时调用追击；出口kind3走独立分支。`3C:D5C8..D5E4` 在事件类型 4、地图模式且 `7AC4==0` 时也调用。

## 4 秒定时服务

留存的原机代码总线帧 `tmp/np560-tjfy-room-event-20260918-v2/event-code.json`，键 `034154`，显示 `03:4154 = SJMP 31:71D2`；装载覆盖对应 source `4E:71D2..7284`。原始 `NP560.PRG` 中的服务：

- 参数为 0 时关闭 `A2:2A4E` 的 bit 4。
- 正参数换算 `floor(ms*64/1000)`，正参数计算结果为零时钳至 1。
- 计数写到 `2A72`，并通过 IGNDS0 写共享 RAM `0496`，设置 bit 4。
- 原厂 TBC 为 64 Hz，ISR `08:40D0..4278` 递减 `0496`；时基硬件证据见 [NP560 时基](../hardware/np560_timebase.md)。
- runtime `29:3DD2` 在 `0496==0` 且 bit 4 生效时交付 type 4 / F1 并清除使能位。
- source `3C:D498..D4A2` 初始化传入 `0x0FA0`（4000）；`3C:D732..D73C` 在处理 type 4 后再次设置 4000。因此为 256 个时基计数，即 4 秒。

SDL 使用 `SDL_GetTicks` 与可回绕的截止时间，每个到期事件只更新一次并从处理时间重新安排 4 秒，不积压补跑。非地图模式和存档槽菜单只消耗并重设事件；同步对白／菜单等待结束时，消耗其中已到期的事件，以对应原厂交互抑制。现已在追击之后接入[NPC周期移动](np560_npe_npc_periodic.md)，15组位置／方向和RNG对照、原始首周期C／SDL整屏通过。原厂整条周期处理链仍未标完成：更多擦除／重叠缓存、其它服务联动、64Hz相位及阻塞交互期间的准确分派时序继续验证。

## 战斗、图像与存档

接触时 `3A:5B5C..5B9A` 清遇敌计数，写模式 3、事件 0、子类型 slot+1。`39:B08E..B10C` 从追击记录的敌人号建立单敌战。胜利后 `33:C59C..C5DE` 写该槽冷却 5 并回地图；成功逃跑是否还有其它追击副作用尚需原机核对。C 追击战沿用当前战斗规则的零体力角色入口初始化，原机此类追击战下的零体力边界未单独采样。

头部向量由 source `31:E956..EAAC` 顺序读取，第三项即文件 `0x1C` / `vectors[2]` 写入 `52:7AEE`。绘图 `3A:5E64..5F26` 用 `7AEE + graphic` 取当前 NPE 位图；不是固定游戏的猪或人物素材。其屏幕坐标为 `(X-scrollX)*16, (Y-scrollY)*16-12`，仅当 `0<X-scrollX<14` 且 `0<Y-scrollY<6` 绘制。V1.3 对应的两幅图为 32×32。

C 存档从 `NPESAV13` 起新增两槽 X、Y（各 16 位）、冷却（8 位），共 10 字节。V1～V12 因没有这些字段，读回时从当前地图 NPE 记录初始化；V5～V11 的 NPC 坐标迁移继续有效。当前写 V14，另保存第 0 组动态地形；此处为宿主存档设计，尚未与原厂存档互通。
