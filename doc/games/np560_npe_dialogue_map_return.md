# 普通对白及故事返回地图的初始化

2026-10-07。生产仍是 C11＋SDL2，本文三条入口均读取未修改的当前NPE对白、故事及后续。

## 固件规则与修复

原NPC控制器在 `3B:76DA` 请求7AB4初始化，恢复保留画面，并在 `76E8` 提交；商店Enter快捷关闭也在 `7792` 请求初始化，但只恢复画面。之前C只在模式14等少数后续中设置该标志，普通对白返回模式1时漏掉保留曲槽的重播。

现在 `show_dialogue_pages` 在恢复保留画面前请求初始化，普通返回、故事及商店后续都保留这个请求。故事页面在 `43:6914` 提交后、`6920` 清7AB4，最后关闭在 `43:695E` 再请求初始化；C的全屏和窗口故事按同样顺序处理。数字后端接口的立即执行行为保持，保存格式仍为NPESAV17。

返回地图的原 `37:1354` 先恢复保留平面，`1366` 再调用地图装载绘图；`4C:6BB8..6BE4` 从保留平面恢复上下边缘。相关回归发现对白覆盖出口提示时，C使用驻留清色重建边缘，产生1920像素差异。现在初始化提交恢复对应的保留边缘，既有45次出口／商店对白实际画面重新全部匹配。没有地图、NPC或故事编号分支。

本轮源指令：`tmp/dialogue-return-original-source.asm`、`story-entry-map-init-original-source.asm`、`dialogue-map-return-original-source.asm`。7AB4的最终消费、音乐槽及地图服务沿用[模式14缓存](np560_npe_story_cache.md)与[对白后续调度](np560_npe_story_followup_dispatch.md)中的原源依据。

实际 `main.c` 探针从同一NPE构造世界，使用SDL的Space输入、原文本分页及正常显示调度。46次240×120完整索引像素及SDL ARGB读回全部零差异；250个有效NPC状态字节、玩家位置／视口／朝向、20个NPC位置及最终模式／事件／进度匹配。每个故事等待输入时初始化标志为0，最后关闭时重新为1，返回地图后为0。

原参考音乐关闭无播放请求，C暂停的SDL游标保持128；开启时原停止／重播22号曲，C播放请求在最后地图提交之前，游标重置0。C RNG11保持。原RNG与PCM未在此采样比对。
