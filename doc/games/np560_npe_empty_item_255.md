# NPE 战斗空列表确认与道具 255

2026-10-06。C11 + SDL2 已接入本分支。原厂运行只作为离线参考，
程序运行直接读取当前 NPE，不依赖 WASM、Node 或 Python。

## 原厂实际装载

空列表的选择字 `7A4C=FFFF`，确认后取低字节为道具 ID 255。
`3F:C370..C846` 不检查道具记录总数，也不要求名称非空：
它从段 2 的 `(ID−1)×4` 位置取偏移，再读固定字段和零结尾文字。

《天降风云 V1.3》实际有 175 个道具。第 255 项的四字节位置已经落入
记录内容，在该文件中读出偏移 0，因此原厂把道具偏移表本身解释成道具。
以下数值来自原厂 RAM，不是 C 版预设值：

| 字段 | 原厂值 |
| --- | --- |
| ID / 类型 | 255 / 0 |
| +35 标记 / 群体 / 阵营 | 192 / 0 / 0 |
| 体字 / 气字 / 攻字 | 3 / 55808 / 4 |
| 名称、说明 | 空 |

这不是上一件道具的缓存。类型 0 在该样本中消耗行动，不直接改变体／气。
“使用”按敌方阵营拒绝；“投掷”按普通敌方目标流程选人或自动提交。

`npe_battle_item` 依照当前文件读取上述偏移，不把 ID 255 写死为无效果道具。
普通资源检查接口 `npe_item` 仍检查实际记录数量。
隔离解码探针将内存副本的第 255 项偏移指向草药，C 版相应读出类型 1、
补 40 体、友方阵营；原文件没有修改。

## 数量地址与战后复制

库存字地址为 `67C8 + 2×ID`。ID 255 对应 `69C6`，恰好是第一名
地图角色的姓名头字。原厂有独立的战斗角色记录，因此行为是：

| 操作 | 地图姓名头字 | 战斗姓名头字 |
| --- | --- | --- |
| 本样本入战 | 49853 | 49853 |
| 空投掷确认 | 49852 | 49853 |
| 取消目标或退上一名角色 | 49853 | 49853 |
| 三人分别确认空投掷 | 49850 | 49853 |
| 执行、被围攻／失败逃跑覆盖、执行前倒地 | 不退还预扣 | 49853 |
| 胜利、败北、成功逃跑离场 | 恢复为 49853 | 49853 |

离场恢复并非额外退款：`2F:C1E2..C24E` 把每个 148 字节战斗角色记录
从 `6450+i×148` 复制到 `69C6+i×148`。复制覆盖了地图姓名的临时改变。
源码位置包括 `C206` 乘 148、`C20C` 源地址、`C220` 目标地址和
`C230` 的 `SCALL 03:4068`。

C 版以两个临时姓名头字保持此别名关系；正常库存 ID 0～254 不受影响。
三个战斗入口都从当前 NPE 的首名在队角色初始化，三种离场路径执行恢复。
本分支不留下永久姓名变化，`NPESAV14` 格式没有调整。

## 空列表的两种画面

初次打开为空时显示原厂“暂无道具!”。确认投掷后取消目标，原厂重新绘制
空道具详情页：没有名称和数量，但保留选择框，并画出第 255 项图像。
这张图像来自当前 NPE 图像表的道具起点加 254，本文件中是 33×32 的闪电图。
C 版读取原图并按 LCD 边界裁剪，没有添加替代素材。

原厂目标页在体力 10000/10000 时，数字右端覆盖到队员图像。
像素参考确认数字采用白底、不透明的 6×12 字符单元；C 版修正为同样绘制，
包含字形右侧一列与底部两行。原先 196 张参考也全部通过回归。

## 验证与范围

- `empty-item-probe`：十组原厂独立夹具的 **36 个阶段检查点**，比较行动角色、
  模式和地图姓名头字；覆盖取消重选、退上一人、阵营拒绝、三人连按、
  围攻／失败逃跑覆盖、倒地跳过、胜利／败北／成功逃跑。
- 解码检查覆盖全部 175 个正常道具、ID 255 的真实偏移表读取、重定向内存副本、
  截断读取以及 ID 0／256 拒绝。
- `sdl-battle-item-flow-probe`：新增 **4 个实际 SDL 按键场景**，累计 15 个。
- `magic-list-probe`：新增空列表、取消后的详情、使用拒绝和投掷目标页
  **4 张 240×120 整屏零差异**，累计 200 张。
- 全量构建、ctest 5/5、投掷预扣 29 阶段、失败逃跑六组、敌方规则、
  SDL 攻击／投掷 10、仙术 7、围攻 3、逃跑 5 场景回归通过。
- 连续 C 路线再次到主线 173、告别和标题，仍为 **21 份角色属性诊断档**。
  原属性前段到 10；野猪战 9 次操作剩 56 体／6 气；花胶实际掉落 15 份、384 次往返。

原厂空列表样本独立设置编组、背包和角色属性，不计为连续剧情进度。
状态检查没有同步两端 RNG，不宣称每次伤害相同；连续剧情仍只修改角色属性，
未手改敌人、地图、NPC、库存、条件、进度或 NPE。
