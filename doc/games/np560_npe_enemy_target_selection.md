## 原厂分支

`32:D474..D53A` 先检查在队角色是否至少有一人体力为正。
`32:D572..D5D6` 检查当前敌人战斗记录的三个技能字节
`6469/646A/646B + 0x94 * 敌人记录索引`；全部为空时进入 `32:DE2A`。
普通攻击分支在目标类别字节 `64D4` 为 0 时进入以下逻辑：

| 源地址 | 行为 |
| --- | --- |
| `32:E09A..E0BA` | 调用 `03:4124` 一次，先对 100 求余，再对队伍人数 `7AFA` 求余，加 1 写入临时一基目标 `7AC0` |
| `32:E0F8..E13C` | 检查该目标战斗记录的当前体力 `64A0 + 0x94 * (目标−1)` |
| `32:E0C2..E0F4` | 目标体力不为正时向后扫描，超过人数后回到 1；不重新抽随机数 |
| `32:E140..E18E` | 把选定的一基目标写入行动者记录 `64CE + 0x94 * 行动者索引` |

队伍人数包含在队但倒下的角色，因此不能直接从存活者列表等概率抽取。
先对 100 求余也不能省略：三人队伍中 `100 % 100 % 3 = 0`，
直接 `100 % 3 = 1` 会选到另一名角色。

## C 实现与验证

`npe_battle_party_target` 将在队角色映射为紧凑顺序，包含倒下角色，再按
上述规则选择；无存活者返回 −1。当前按速度排定行动，在轮到敌人时调用一次，
随后取浮动和属性的两次随机数。角色的所有实际行动也先取这两次随机数。
敌方仙术尚未执行；有仙术敌人的策略随机数顺序须随 AI 接入后继续核对。

- `npe-map-test` 覆盖三人目标、100／101、倒下者扫描与绕回、非连续在队槽和无人存活。
- 真实资源世界探针中的隔离反击测试确认：种子 1 攻击第二名队员，
  第一名体力不变；种子 2 初选倒下的第一名后扫描第二名。两名较快防御者
  加一名普通敌人共消耗 7 次，终态 `20D01480`；仅第二名存活防御共 5 次，
  终态 `2A88C8FF`。旧 `8F001A40`／`9C6A019F` 未计防御的两次准备抽取，已撤销。
- 两敌反击测试用独立固定种子验证第一名倒下后，下一名仍可行动及领取经验。
- 修正随机数消耗后，连续路线改为重伤时逃离普通遇敌，并实际到医馆交谈、
  选择治疗和支付 10 两。野猪精仍为原始 500 体，以练级、装备和原始道具胜利。
  前段未改档到进度 10，之后最新 21 份角色属性诊断档继续到 173 并返回标题。
  此结果证明当前 C 剧情链可推进，尚未证明原厂完整战斗规则或原始属性通关。

## 原厂 RAM 采样更正

此前把 WASM 线性内存中的客机 RAM 当作一段连续空间，读敌方体力出现
“500→494→490→500”。本轮发现这种采样跨页取错地址：当前冷启动实例中
客机 `6xxx` 页相对 `7xxx` 页外推位置有 8 字节差，恢复快照后分配地址也会变化。
不能沿用单个基址读取所有客机地址。

本轮独立定位两页后，仅把主角当前体力写为 22；实际确认攻击后自然败战，
验证了角色体力字段的页定位。敌方体力的副本和写入路径仍需核对，旧数值
不足以证明回血、截断或特殊 AI。此前进一步把 NPE 敌人 `+29=6` 解释为
伤害下限也有误，现已由装载链 `31:CE7A..CF20` 确认为第一项仙术。
新的独立原厂回放观察到野猪精选择仙术 6、给自身治疗且气不减少；
这不是旧跨页读数的恢复。C 尚未执行敌方仙术，不能据未解的快照上限差异
将原始 500 体改为 244。完整证据见[敌方行动修正](np560_npe_enemy_action_reconstruction.md)。
