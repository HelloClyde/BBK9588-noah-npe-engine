# 原版装备操作页与多人输入

更新于 2026-10-06。装备入口、角色详情和返回路径使用 C + SDL，
物品名称、图标、肖像和属性效果读取当前 NPE。已删除原装备路径的英文桌面选择／结果窗口。

## 独立原厂按键证据

`tmp/map-native-equip-menu.mjs` 恢复原厂地图快照，在独立 RAM 中设置背包和队伍。
一／二／三人夹具复制原主角记录，保持同一肖像与姓名；仅用于验证人数、输入及装备落到哪个记录。
没有修改磁盘 NPE／PRG，也没有写入连续剧情。

菜单“物品→装备”打开物品列表；确认可装备物品后直接进入角色装备详情，
没有另一个选人对话框。

| 输入／状态 | 原厂结果及 C 实现 |
| --- | --- |
| 进入详情 | 选第一名队员；显示当前穿戴、四状态、三项其他属性、攻防和所选物品数量 |
| 上／下 | 循环切换参战队员；一人保持原位 |
| 左／右 | 详情页忽略，不选择装备槽、不卸装 |
| 确认 | 应用当前 NPE 装备效果，留在详情页，更新库存和属性 |
| 重复确认同一装备 | 原厂归还旧物再穿戴；库存保持，不叠加基础属性 |
| 当前物品数量变零 | 保持当前队员；不能切换队员或继续装备，F4 仍可返回 |
| 详情页 F4 | 回列表，重新扫描库存，移除耗尽项、显示归还旧物 |
| 列表 F4 | 回地图模式 1，不回物品子菜单 |

三人耗尽序列通过上下切换，先装备第三人、再装备第二人；数量变零后，上／确认均无效果。
F4 返回列表只剩物品 91，重新进入详情从第一人开始；确认后列表为空，最后 F4 回地图。

## 页面细节与数量边界

- 穿戴行顺序：头戴、身穿、武器、靴子、披挂、佩戴；对应槽位 `0,2,1,3,4,5`。
- 四状态字的显示名称依次为 **毒、眠、乱、封**。负字拼到“状态”，全部非负显示“正常”；正字拼到“免疫”。
  独立四字全正、全负、第三字正、第四字正采样均已对照。
  旧文中将第三字称为“封”的命名应更正；这轮只证明显示名称，完整乱／封机制仍待核对。
- 山海经的长说明在列表只显示前三行，余文截去；此前 C 因描述超出三行而退出列表的问题已修正。
- 独立数量夹具 `85=100,91=65535`：原厂列表只显示 85，排除有符号负数量。
  数量字段从固定左侧位置显示前两个十进制字符，100 显示“10”，装备后实际库存是 99。
  99 也从同一左侧位置绘制；显示截断不改变实际数量。
