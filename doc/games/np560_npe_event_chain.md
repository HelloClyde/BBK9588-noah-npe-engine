# 通用事件链与主机关闭

更新：2026-10-07。生产程序保持纯 C11＋SDL2。本轮移除 SDL 调度器自行添加的64次链上限，沿用 NPE 各服务产生的模式／事件号继续调度。

## 原版依据

原控制器 `3C:D760` 调用运行时 `2D:F47C`，对应源码调度器 `4A:F47C`；`3C:D764` 无条件回到 `D4E2`。该循环先清输入字 `7A76`、检查退出状态 `7A3C`，再处理输入／调用当前模式服务。它没有64次调度计数。

模式14分支 `4A:F562` 调用地图故事服务。当前地图只装载前八个故事事件，但驻留第15槽仍可使用；本轮诊断设置该槽为进度1／模式14／事件15，即自循环。NPE 文件、地图资源、文字及图像保持原样。

源码摘录：`tmp/event-dispatch-original-source.asm`；提取脚本 `tmp/extract_event_dispatch_source.py`。

## 实现

- `advance_world_events_dispatch` 继续执行各个资源服务，直至进入需要主循环处理的模式、资源服务失败或主机请求关闭。移除64次计数及超限输出；不把重复模式自动改为地图模式。
- 每轮事件前使用 SDL 主线程的 `PumpEvents`／`HasEvent(SDL_QUIT)` 检查关闭，检查本身不取走排队的游戏键。退出请求已在排队时，不再执行下一项服务；已经开始的服务可以完成。
- 关闭状态通过返回值传到实际 `main.c` 主循环，退出前清理宿主显示作用域，跳过后续地图计时／重画。模式2／5的等待函数重新排队的关闭请求也能从调度器返回。
- `advance_world_events` 无论正常返回还是关闭都恢复调用者的显示作用域。资源与世界规则不增加游戏编号特例，保存字段与 `NPESAV17` 不变。

SDL API 使用依据是当前安装的 `C:/msys64/ucrt64/include/SDL2/SDL_events.h`：主线程 Pump 收集输入，Has 查询队列。本机关闭是宿主行为，不等同于原机器按键或退出字的逐指令时序。

## 验证

### 原版自循环短片段

从原标题已存档快照进入地图1，关闭巡逻及遇敌，保留曲槽2／音乐开启，诊断设置驻留第15槽。原版运行 **490次 advance，70次地图提交**，最终仍为模式14／事件15／进度1，地图初始化标志为1，没有地图音乐停止或重播请求。

实际 C 主程序按相同地图、玩家／视口、20个 NPC 位置和250个 NPC 状态字节进入循环。**70幅索引图和70幅实际 SDL ARGB 读回均逐次零差异**；超过旧64次限制后继续执行。第70幅提交时排队 SDL_QUIT，实际主循环退出，最后仍为模式14／事件15／进度1／初始化待处理，音乐游标保持128，C RNG11保持，显示作用域清理为0。原版片段没有采样主机关闭操作；关闭行为由 C 的实际事件队列和主循环验证。

采样：`tmp/native-event-chain.json`、`native-event-chain-0..69.idx`。参考脚本 `tests/reference_event_chain.mjs`、夹具 `event_chain_native.h`、实际程序探针 `sdl-event-chain-probe`。

### 终止、数字后端与关闭

- **C 诊断终止链：** 同一驻留模式14循环，在第70次执行服务前把该槽后续改为模式1／事件777。一轮调度执行70个服务，随后提交返回地图画面，曲槽22从头重播，初始化标志清除。共71次 C／SDL 图像与原地图图像相同。这是测试在受控边界改变驻留资源的 C 检查，不宣称原版采样了相同终止链。
- **C 模式9数字后端：** 寻找当前 NPE 中实际存在的学技记录，在测试内存副本里设置角色1／技能1／后续9／事件1；执行生产解析器及1029次数字后端插入，18个技能槽均为1，模式9保持。之后预先排队 SDL_QUIT，实际调度器在进入服务前退出，世界和调用者显示作用域保持，Space 键未消耗；另一作用域0同样保持。此项是数值及宿主入口检查。

2026-10-07 学技模块对照已更正此前“无LCD学技循环关闭”的解释：原模式9显示名义2000ms学技提示，旧测试不能用作这种显示行为的证明。实际提示、底图恢复、后续及提示中关闭改由[学技服务](np560_npe_skill_service.md)的58次整屏对照验证。历史失败日志保留，原70次模式14显示循环和终止链继续通过。

九个定向构建目标成功且无警告；新事件链、故事事件返回、非法／普通对白、模式2后续、模式14对白后续、NPC字节移动、脚本行走，共 **八项相关短探针最终退出0**。关闭相关回归包含既有非终止 NPC 移动／脚本行走片段。原 NPE／PRG SHA256保持。
