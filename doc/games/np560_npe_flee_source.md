# NPE 战斗逃跑分支

依据 `tmp/NP560-runtime-source-patched-v655.PRG` 的 source 反汇编
`tmp/mode-analysis/modes9_10_16_reachable.asm`，以下地址均为 source 地址。

- 普通战斗入口 `4E:7F74..7F7C` 将 `52:7A9A` 置 0；脚本战斗入口
  `4E:8BC4..8BCC` 将它置 1。
- 战斗行动 `2F:B9D0` 检查当前行动类型 `52:64CF + 0x94×行动者索引`
  是否为 6。类型 6 的后续分支处理逃跑；`2D:507C` 只是动作派发表的
  返回位置。
- 普通战斗在 `2F:B9E4..B9FA` 调用原厂随机服务 `03:4124`，取
  `random % 100`。余数 `<10` 进入 `2F:B9FE..BD96`：把全队指令改为普通攻击，
  设置本回合的继续标志并显示失败提示。余数 `>=10` 进入
  `2F:BD9A..C252`；`2F:C142..C14A` 把游戏模式写为 1。
- 脚本战斗由 `2F:B9E0` 转到 `2F:C256`，不经过上述随机调用。
  `2F:C25E..C260` 只接受 `7A9A=1` 的路径，后续把全队指令改为普通攻击，
  未发现写入地图模式 1 的指令。

原厂实测记录在 `np560_tjfy13_import.md`：一次逃跑失败留在模式 3
并受到伤害，下一次成功返回模式 1。C 版已接入这些模式路径；其
随机服务的递推与输出位已还原，初始状态和战斗整体行动队列仍未完整
核对，因此不能据此宣称逐回合一致。

2026-10-06 追加：原始 PRG 分支和六组原厂独立运行确认失败覆盖后的
一／二／三人普攻顺序、倒地／睡眠跳过、已扣投掷不退，以及剧情失败回普通攻击图标、
随机失败保留旗帜。C/SDL 已修正，见[证据与回归](np560_npe_failed_flee_commands.md)。
