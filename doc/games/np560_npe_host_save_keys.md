# 原版菜单存读档入口与桌面快捷键

2026-10-10。纯C＋SDL主程序已移除早期原型的全局F5／F9第1槽存读档入口。存读档继续由原版系统三槽菜单和标题选槽执行。

## 发现与修正

原系统和标题控制器通过菜单、选槽和确认分派保存／读取。早期原型额外在主输入循环处理SDL F5／F9，绕过这些页面直接调用自身存档API；F9还能从非地图模式恢复第1槽。`PORTABLE.md`此前将这两个入口注明为临时快捷键。

本轮删除两个全局分支及其桌面消息框。游戏模式的动态窗口标题改为`NPE`，清除旧F9、战斗D／F操作提示和运行状态调试信息；实际游戏标题、画面和文字仍由当前NPE资源及原字体绘制。资源查看器的独立诊断标题保留。

原系统三槽成功、失败、取消及标题选槽代码继续使用原分派。自身存档格式无需变化。

## 修复前的实际失败

行走探针在原参考地图页面中注入F5；诊断存档适配器实际拦截到保存调用并失败：`Non-original F5 reached the save service`。拦截发生在写文件和消息框之前，没有覆盖玩家存档或打开弹窗。

日志：`tmp/host-save-keys-before-failure.log`。原型源码及旧包保存在`tmp/host-save-keys-before/`。

## 修复后检查

F5／F9是本次SDL桌面输入，不是原机键盘采样。原参考用于周围有效菜单／移动路径，新增输入检查用于验证桌面键不触发额外服务；没有将这两种证据冒称为原机F5／F9测试。

| 实际生产输入路径 | 新增SDL F5／F9检查 | 沿用原C／SDL画面对照 |
| --- | ---: | ---: |
| 地图主输入 | 20 | 直接显示42＋主循环42 |
| 系统根菜单／子菜单 | 152 | 77 |
| 系统存读档页面 | 56 | 33 |
| 标题／选槽 | 44 | 24 |
| 合计 | 272 | 218 |

地图检查保持画面、坐标、朝向、事件、随机和计时状态，并禁止调用存档／恢复适配器。系统／标题检查保持World、选槽控制字段和LCD，无额外提交。所有新增输入位于既有原参考输入之间，原参考和有效输入顺序未重新生成。

三槽探针此前在“读第2槽后保存第1槽”步骤使用F5。本轮改成实际F4进入系统菜单，选择存档和第1槽；创建、覆盖第2槽、取消覆盖、从标题读取及通过菜单保存第1槽全部通过。它只操作自有`SLOT-FLOW-01`诊断游戏和存档，不是原机存档互通。

四个输入探针及三槽探针退出0。主程序和优化Release构建无警告。便携包重新安装／打包后，项目外路径、四份NPE解析／SDL标题／自身冷存档、原三槽短路径、实际有限启动和字体错误处理的14项交付检查通过。

汇总：`tmp/host-save-keys-report.json`；交付：`tmp/host-save-keys-portable-report.json`；日志使用`tmp/host-save-keys-`前缀。`npe-sdl/tests/verify_host_save_keys.py`核对本批已记录结果、生产入口和包内程序，未用C输出生成原参考。

## 范围
