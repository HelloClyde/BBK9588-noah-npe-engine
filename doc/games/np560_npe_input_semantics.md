## 原厂扫描门槛的直接执行核对（2026-09-18）

原厂 `27:E528`（PRG source `44:E528`）先读 F160；全释放时把
`A2:2A94` 置 1、字节计数 `2A8C` 清零。有电平时先调用 `31:BE70`，

`31:BE70` 对应 PRG `0x2EBE70..0x2EBF0D`，共 158 字节：

- 每次调用增加字节计数；rearm 非零时计数不足 2 返回 0。
- 第二次调用清 rearm、清计数并返回 1；不是第一次电平出现就产生事件。
