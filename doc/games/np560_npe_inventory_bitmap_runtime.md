## 原选择与绘制顺序

原物理 `31:EA14..EAAC` 将NPE头的第5～8图组基址依次读入 `52:7AE4/7AF8/7AEC/7AEA`。运行时初始化这些字；`npe_image_group_index` 使用当前驻留字加序号，保留16位回绕。

- 原道具列表 `3F:0E1A`、道具／装备目标 `2F:54BC` 使用 `7AE4 + itemID`。C移除扫描连续32像素图标的推断，零基预览接口转换为ID后也使用当前图组；原完整16位目标编号接口保留回绕。
- 原道具列表 `3F:0DF8..0E02` 和仙术列表 `3B:6170..617A` 都使用 UI组＋17、模式0。道具位置为 `25+列×73,18+行×16`，仙术为 `25+列×73,13+行×16`；不再搜索图像特征或自行画三角形。
- 原道具／装备目标 `2F:59BA..5A1E` 按数量、肖像顺序，肖像在 `(1,1)` 不透明绘制；仙术列表肖像在 `(1,52)`，仙术目标在 `(12,1)`，均使用原通用位图服务。
- 原仙术目标 `33:EF66..EF8C` 将技能组＋ID的整张图画到 `(22,63)`。先画完整图标，随后费用文字的固定不透明区域覆盖底部；撤掉旧的只复制30行处理。名称、标签、肖像和数值的既有顺序保持。

库存图标、道具和装备目标图标／肖像、仙术列表肖像／光标、仙术目标图标／肖像均进入同一客机堆／文件读取／原绘图服务。`text.c` 已无逐像素复制NPE位图的调用；字体、边框及数值绘制仍使用各自的原服务移植。
