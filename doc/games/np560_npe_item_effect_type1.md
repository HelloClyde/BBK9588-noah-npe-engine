# NPE 恢复道具记录与 C 版使用逻辑

第 2 段物品记录以零基索引读取，地图和背包的物品号从 1 开始。
记录 `+12` 是效果类型；类型 1 的 `+13..14`、`+15..16` 分别为
大端 16 位体力、气力恢复量。

| 游戏／物品号 | 原始记录效果字段 | 原厂运行证据 |
| --- | --- | --- |
| 《天降风云》46 草药 | `01 00 28 00 00`，体力 +40 | 《英雄传奇》同一条草药，使用后生命 52→92、数量 1→0；见 `np560_npe_battle_observation.md` |
| 《天降风云》55 灵芝 | `01 00 00 00 3C`，气力 +60 | 2026-10-06 原厂独立战斗采样气 20→80，C 隔离效果对照通过；见后续记录 |
| 《英雄传奇》55 灵芝 | `01 00 05 00 28`，体力 +5、气力 +40 | `np560_npe_battle_observation.md` 的原厂道具说明和战斗使用记录 |

C 版 `npe_world_use_item` 对类型 1 将恢复值加到目标角色的当前值，
按上限截断，并将对应背包数量减一。地图模式临时 `U` 菜单把此操作
接给首名角色。《天降风云》龙眼 69 在原厂可消耗，截图显示免疫“眠”；
状态字段和完整效果规则尚未核对。
C 版现依据类型 2 记录 `+31..32` 的 +5 保存正向眠防护值并消耗龙眼；
前期战斗中使用后曾进入临时敌方回应。该数值是否按回合递减、如何解除已有睡眠
以及其它负向状态效果仍未验证。

2026-10-06 战斗路径已接入原厂多人命令队列、预扣／退还和友方目标，类型 2 按四状态
有符号字加法执行；正免疫不按负状态递减。这里的旧地图三状态实现仍待补全。
现状与原厂采样见[战斗道具记录](np560_npe_battle_use_items.md)。
