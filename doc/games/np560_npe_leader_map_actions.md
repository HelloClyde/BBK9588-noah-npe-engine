# 队首切换后的地图动作：方向、无目标与调查坐标

## 原固件与修正

反汇编：`tmp/facing-direction-original-source.asm`。NPC选择器 source `33:3752..450E`，物件选择器 `46:CE22..D0B8`，地图输入控制器 `37:139A..161A`。文件中的跳转表数据行不作为已执行指令证明。

- NPC／固定怪物选择器在 `33:37F0/37F6`、`3F10/3F16` 检查方向范围。超出0～3时跳过所有候选，最后 `44FA` 返回FFFF，即没有目标。
- 物件选择器 `46:CEAE/CEB4` 同样跳过候选，`D0A8` 返回FFFF。
- C原先将方向大于3当成错误。模式13把原第二角色的方向4带到首位后，空格会走到实际main的错误退出；现返回无目标0，保留角色、事件及方向。
- 无目标交谈 `37:13C2`、无物件 `37:142E`、已领取 `37:148C` 都直接返回，不提交新LCD。实际C主循环保留当前平面，撤掉空格／调查无目标后的额外重画。
- 原调查 `46:CE3A..CE62` 与NPC一样用屏幕坐标＋视口偏移。C原先用请求落点 `world.x/y`，已改为当前视口；原底边装载可能使这两者不同。
