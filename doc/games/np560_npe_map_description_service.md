# 地图道具／技能说明的原共享切页

日期：2026-10-09。本批接入地图道具90字节与技能112字节说明的入口及前后翻页，完整引擎尚未完成。

## 原程序依据与改动

道具入口为PRG3F:0E78..0F46，前后页为4D:8EFE／A946；技能入口为3B:6366..6426，前后页为47:572E／59A2的menu11分支。均调用CPU28:031E的原子串函数。道具入口使用8位回绕长度索引；技能入口索引为无符号16位；共享子串自身仍使用有符号16位索引。

`text.c`改为读取当前NPE的实时驻留道具／技能缓存，再调用原子串函数生成调用者局部文字。入口重设长度、首尾；前后页保留长度。后页仅在end==length-1时停止，前页要求有符号start>0；越界、word回绕、回退到0均遵循原计算。绘制消耗实际NUL字符串，不把返回长度当作宿主源字符串区间。

格式器使用原紧凑字符格：控制字符占一格空白，CR／LF不自行换行。2026-10-10宽头像原对照纠正后页清除坐标：前后页都从y59清除，文字仍从y60绘制；入口按占用字符格绘制背景，未占用区域保留。见[技能说明保留](np560_npe_magic_description_retention.md)。其它文字格式器行为仍待还原。

实际SDL的技能列表补上n／p前后页键；目标选择时不执行这两个键。道具入口同时补设原事件号2。新样本起初发现原程序mode4／event2而C仍留event0；修复入口后状态对照通过。

## 验证范围

14条原路径：道具和技能各7条，覆盖标准文字、混合汉字边界、控制字符、末页停止、word回绕、越界空页、负索引停止。原技能装载器的说明读取上限为101字节，本组通过修改实时分页字段进入前后页分支，未把缓存溢出当作正常资源。

原参考`tmp/native-map-description-service.json`。核心与实际SDL比较完整LCD以及模式／事件／属性页／人物选择、分页字段、142字节道具缓存、144字节技能缓存和人物属性；7A54菜单字段尚未绑定，不能声称该字段对照。核心32次原页画面／状态对照，实际SDL32次原页及7次角色选择页对照零差异；8次边界停止无提交。临时堆句柄位图恢复。实际主循环探针在最后一页后用主机关闭结束，未把该结束当作原F4关闭提交证明。

初次把技能说明强行延长到115字节会覆盖记录属性，两组人工缓存采样在原运行时发生execution_fault，未作为有效路径；日志和两版producer保留。有效样本保留合法属性记录，用长度／首尾控制字段检查分支。

新SDL探针首次仅按新游戏NPC位置构造输入地图，角色选择页的一个NPC区域相差501像素；重新记录原采样期间的NPC位置，按该输入状态构造测试。前一次不含NPC状态的原样本另行保留，重新采样的全部已有LCD哈希核对。此处证明说明控制器在相同输入状态下的行为，不证明整个物理时序或任意NPC生命周期。
