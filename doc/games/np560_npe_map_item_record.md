# 地图道具菜单的共享记录（2026-10-08）

生产程序为纯 C11＋SDL2，列表名称、说明、图标及属性读取当前 NPE。原 PRG／WASM 仅用于离线核对。此轮接入地图“物品→使用”；装备选择、战斗及其它共享记录调用仍需继续核对。

## 原服务顺序

- `3F:0A42` 接收整页／详情重画标志和选中词。整页依次对每个可见库存项调用 `22:C370` 共享装载、画缓存名称和数量，最后再装载选中项的说明。不能先装载选中项或对每个名字直接读文件，否则旧缓存同编号时的名称不同。
- `3F:0A60` 在详情重画时跳过网格。方向处理只擦旧光标、图标和说明；名称和数量留在 LCD 上。擦光标矩形是 `x=20+列*73..38+列*73`、`y=18+行*16..22+行*16`，与光标本身的 x25 起点不同，可能擦掉名称底行部分像素。
- 列表为三列四行。跨页重画网格，同页移动仅重画详情。选中词保留在 `7A4C`，行／列分别是 `7A20/7A22`。采样中的 `7A24` 跨页仍为1，此轮没有把它当作页数模拟。
- 初次详情将 `7ABA` 说明长度、`7ABE` 起点和 `7ABC` 终点重设，取最多90字节；所取高位字节数为奇数时少取一个字节。100字节的混合 ASCII／GBK 样本第一页结束于88，下一页从89到99。
- `4D:A946`／`4D:8EFE` 的说明下一页／上一页先检查旧边界，再调用共享装载。无效边界无 LCD 提交、无装载。C／SDL 绑定 **N／P**；列表左右仍用方向键，并支持原机 **J／L**。
- 空背包选中词写FFFF，显示“背包为空”，不清共享142字节及说明长度／起止位置。空背包确认和方向键无提交。
- 地图确认 `2F:15DA`、人物目标页 `2F:54E4`、效果服务 `30:956A` 都调用共享装载。`npe_world_use_item` 现在读缓存属性；相同编号沿用旧效果。装备／敌方／剧情道具拒绝也可能改变装载缓存，不能用整个世界不变作为拒绝断言。

纯资源预览接口保留直接读 NPE 的行为；实际地图菜单使用有世界状态的接口，人物页已装载时读取缓存名称。库存扫描只检查正的有符号数量；资源在可见项装载时读取。
