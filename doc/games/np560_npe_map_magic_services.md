## 原厂地图分派

`3F:23C4` 逐字段装载仙术：文件 +14 → `7382`，+37 → `7383`，+38 → `7384`。
`37:D1E4..D20A` 先检查 `7384`：零则显示原厂“该魔法只能对敌人使用!”，不扣气。
`D24E`／`D418` 对气与费用做有符号字比较，不足显示“魔法值不足!”。
提示服务传入 2000 ms；当前 SDL 使用相同时间的原版覆盖框。

地图的 `30:9444` 与战斗效果服务不同：

- 仙术分支 `9494..955E` 装载体力／气及四项状态字；攻、防、灵力、幸运、身法准备值清零。
- 类型 1、单体在 `9668..9A88` 更新所选地图角色；群体在 `9A8C..9F12` 遍历三个槽，
  只检查是否在队。它们均不检查当前体力是否为零。
- 体力／气加法保留低 16 位，与上限做有符号比较，只夹超过上限的结果。
- 调用者 `37:D2E6`／`D4B6` 在目标效果执行后扣施法者费用；自疗／群体补气须先夹上限再扣费。
- 类型 16～19 在这条地图服务中没有复活分支，直接返回调用者，仍扣气。
  不把战斗复活规则或技能说明自行移入地图路径。
- 类型 2 四字与装备正状态重建已在后续完成，见[追加证据](np560_npe_map_status_and_equipment.md)；下文保留前一轮采样范围。

因此地图增益术可能只扣气、面板攻防不变；“回魂咒”在本次地图采样中也只扣气。
这不是根据名字推断的规则，实际按键和原厂源码均有对应结果。

## 独立实际按键参考

用原在线包冷启动新游戏，在独立实例中设置角色属性和已学仙术前缀，
三人场景复制完整原角色记录；不修改源 NPE、PRG 或连续剧情存档。
实际按 F4 → 仙术 → 选角色 → 列表 → 确认，记录地图角色体力／气。

| 6，体 0 | 体 100、气 89；零体力者能施法并能作为目标 |

## SDL 与画面

`show_magic_list` 已移除临时英文桌面仙术摘要，接入：

- 一至三名在队角色的原版选人框；名字从当前 NPE 角色记录读取，含零体力角色。
- 每名角色自己的动态已学前缀及等级门槛，三列九项列表和滚动。
- 原厂阵营拒绝及气不足覆盖框；单体进入原版目标属性页，群体在列表直接施放。
- 目标页返回列表，列表返回选人，再返回系统菜单；施法后可以继续确认。

新增七个真实 SDL 按键场景通过：单疗、三人群疗、零体力目标、零体力施法者的
地图类型 19、不同行动者／目标、双技能选择和取消不扣气。
这是实际 SDL 事件进入生产页面，不仅调用规则 API。

原厂像素对照：

- 一／二／三人菜单及上下移动共 **9 个菜单裁剪区**零差异，包括不等高的选中范围。
- 单技能治疗列表、列表上的气不足、敌用术拒绝 **3 张 240×120 整屏**零差异。
- 原有 200 张整屏回归仍通过，已核对整屏累计 **203 张**；菜单裁剪不计为新增整屏。

本轮未核对地图多技能滚动的逐帧画面、所有空术提示与按键、整个地图背景／人物帧，
或所有地图状态页。采用已核对的公共列表实现不等于这些路径已独立像素验收。
