# 地图任务道具：类型 24 与事件续接

更新于 2026-10-06。生产路径为纯 C11 + SDL2，直接读取当前 NPE 地图第 7 组。
规则来自原厂 PRG 反汇编与独立原厂按键采样；不按游戏名称或道具 ID 写特殊剧情。

## 地图记录

原厂地图装载 `29:E148..E37C` 丢弃记录号，按顺序展开到 `75DE` 的五个十二字节槽。
NPE 的每条记录为十三字节；所有双字节字段均为大端。

| NPE 偏移 | 字段 | 本轮实现 |
| --- | --- | --- |
| +0 | 记录号，2 字节 | 读取，但不作为槽号；原厂按序装载 |
| +2 | 最低剧情进度，2 字节 | 当前进度无符号大于或等于才匹配 |
| +4 | 道具 ID，2 字节 | 必须等于本次使用的道具 |
| +6 | 后续模式，1 字节 | 交给已有事件分派；原厂模式 0 返回地图 |
| +7 | 后续事件 ID，2 字节 | 使用当前 NPE 的事件记录 |
| +9/+10 | 角色 X/Y，各 1 字节 | 两者同时为零才免位置检查；单个零是实际坐标 |
| +11 | 所需面对的 NPC ID，2 字节 | 零免检查；非零须面对当前活动的对应 NPC |

`npe_map_quest_item` 接入现有地图分组解析，限制最多五条并验证跨度等于条数乘十三。
空表返回无记录；超容量、跨度不符或非法槽号拒绝解析，不尝试补造数据。

## 使用与后续事件

地图调用 `2F:1654..19A4` 先判断类型 24，再进入普通道具的阵营门槛。
本轮保留这个顺序：类型 24 的群体与阵营字段不决定能否使用。

- 顺序检查五个槽，选择第一条满足道具、进度、角色位置及面对 NPC 的记录。
- 位置检查角色自身的绝对地图坐标；NPC 检查面对的相邻格。
  复用固定 NPC／地图编组解析、活动进度范围及实时移动覆盖。
- 匹配后扣一件，设置后续模式／事件及原厂 `7938` 对应的 NPC 上下文，清除旧 NPC 对话缓存。
  原厂先清 LCD；C 版在后续对白链保留清屏背景，回地图时恢复地图绘制。
- 不匹配不改变数量或剧情。显示原文“不能使用!”，等待最多两秒，可由按键结束；结束键在提示内消费。
- 已实测直接模式 14 进度事件、模式 0 返回地图、故事→进度事件→地图、任务道具→NPC 对话→地图。
  其他后续模式复用已有服务，尚未逐种新增任务道具入口的独立原厂验收。

`event_context_id` 与 `event_blank_background` 是暂态字段。原厂 `7938` 还有其他用途，
这里仅实现已核对的任务入口上下文，不宣称完整替代该固件字。
存档仍为 `NPESAV15`，地图存读布局未变；没有新增事件中途保存能力。
