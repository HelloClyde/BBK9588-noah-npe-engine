# 地图仙术菜单与共享技能记录

更新：2026-10-08。此轮把地图菜单接入已实现的 `7A74 / 730E` 共享技能服务，按原指令核对列表、目标页和施法。生产程序使用纯 C11 与 SDL2；Node/Python 仅用于提取参考和生成测试夹具。

## 原指令与实现

- 源 `49:E54E..E65E`：从角色18字节技能前缀逐个装载共享记录，再比较 `7381` 等级。遇0或首个超等级记录停止，重复编号保留；停止处的候选记录仍驻留。`7ADC` 是施法者，`7A18` 保存数量。
- 源 `3B:5F6C..60BA`：列表名称直接读取当前 NPE；详情在 `3B:61EE` 装载选中共享记录，用缓存说明和费用。资源名称与驻留名称可以不同。相同窗口移动保留名称区域，擦除旧光标；跨窗口才重读可见名称。空列表保留旧技能缓存和说明索引。
- 说明重设 `7ABA` 长度、`7ABE=0` 和 `7ABC` 终点，原分片上限112字节，取高位字节为奇数时减一。本轮动态核对100字节混合 ASCII/GBK 说明，112字节边界仍待采样。
- 源 `33:EE80` 是仙术目标显示。`33:EF16` 在更新时跳过静态边框、图标、名称和标签；头像、费用与人物值继续刷新。`33:EFA4/F238` 调用共享装载。费用和左值占7个紧凑字符单元，右值占8个。运行段 `31:465E`（PRG源 `4E:465E`）格式为 `%d`，16位属性和费用按有符号数显示。
- `33:EF7A..EF88` 图标编号是 NPE 头中 `7AEA` 对应基址加仙术编号，C 使用 `file->vectors[8] + skill_id` 的16位结果。撤掉目标页固定使用第一种仙术图标的错误。`31:E956..EAAA` 文件头初始化也已单独保存反汇编。
- `37:D1DA/D2E6/D4B6` 与 `30:949C`：阵营、群体、效果、费用使用共享记录；先作用目标，再扣施法者的气。相同编号沿用缓存，换编号读取 NPE。数字后端保留既有技能成员资格检查，菜单已先做前缀/等级门槛；异常前缀和绕过菜单的完整原行为仍需核对。
- 选人页沿用主菜单保留的地图底图，金额用原厂紧凑字体。F4直接关闭整个地图系统菜单；忽略键、空列表确认、无变化的方向边界不额外提交。拒绝提示提交后恢复原底图。

## 更正与保留的失败

1. 初版把F4当退回上一级，多发F4实际退出后又打开主菜单；改为一次退出。`mask32` 尝试没有证明取消键送达，不能当作原取消流程通过，尝试JSON和日志均保留。
2. 初次选人差1820像素：56是金额数字字体，1764是冷构造器色2与暖参考色0的地图边缘。改为沿用真实菜单底图并使用紧凑金额字体；探针构造正确的暖调用者背景。
3. 首次目标页901像素来自错误固定图标，按NPE基址+编号修正。更新目标时多清一行导致32像素差异，原图标底行应保留。
4. 按原固定值区域刷新时，初稿紧凑字体只画前景，没有清旧值，产生110像素差异；已补固定区域清除，保留静态标签/图标/名称。宏编辑的编译错误也已修复，日志保留。
5. 旧《英雄传奇》测试把首次装载缓存当成“世界状态不变”；补齐原列表已装载技能11的调用者状态，保留原像素哈希不变。旧SDL地图流程的多次F4脚本也已缩短为原一次退出。
