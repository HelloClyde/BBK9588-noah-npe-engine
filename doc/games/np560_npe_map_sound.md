# 地图音乐实时目录与声音开关顺序

范围：纯C地图音乐请求服务、实时曲目槽／驻留目录、控制器的声音word条件，以及设置开关时的请求顺序。原函数参考来自`tmp/NP560.PRG`；原文件保持。

## 原版规则

| 调用位置（源地址） | 原行为 |
| --- | --- |
| 31:F1A6..F288 | 将当前NPE第20..22节的完整32位偏移、长度存入地图音乐目录 |
| 48:23B2..23D4 | 声音word非零时取一次共享随机数，余数模3写入地图曲目槽 |
| 37:1324..1344 | 地图初始化标志非零且声音word恰好为1，才调用地图重播服务 |
| 4E:A3F4..A498（CPU31:A3F4） | 服务自身没有声音开关判断；读取当前槽52:7A04、长度52:78F2+4×槽、偏移52:78FE+4×槽 |
| 37:CFDE..D02C | 设置“开”先调用重播再写声音word=1；设置“关”先停止再写word=0；之后设置模式与初始化标志 |

播放参数为文件名52:6EBA、完整32位偏移、完整32位长度、两个空远指针，最后是CPU31:A3F4结束回调。长度没有战斗动作选择器的低16位符号扩展规则。曲目槽3和255按原地址运算读取相邻RAM，不限制为0..2。

## C与SDL实现

- `map_sound.inc`实现不带开关判断的原重播请求服务；资源运行时读取实时RAM，不用固定段号替代缓存。
- `rpg_runtime.inc`初始化当前NPE三组地图目录，后续修改目录仍会影响请求。
- `resident_resources.inc`绑定曲目槽的高字节；相邻低字节仍由运行时RAM保留。World绑定由3547增至3548字节。
- `npe_world_sound_map_resume`按完整声音word==1判断；`npe_world_music_set`先请求播放／停止，再修改声音word。
- 范围观察者增加loop参数：地图请求循环，战斗动作请求有限播放。SDL直接读取当前NPE范围，错误范围停止候选播放，不替换为其它曲目。
- 战斗动作声音请求移到两次动作准备随机数之后；检查普通攻击请求时的RNG与两个准备字段。原初始绘图与声音请求的完整调用时点仍未对齐。
- 自身NPESAV22序列化保持；既有暖恢复保留曲目槽与观察者。

## 证据与复现

原片段采样器：`npe-sdl/tests/reference_map_sound.py`。仅替换播放／停止向量和指定片段返回边界，入口前通过客机指令设置状态，不通过宿主直接改写客机RAM。采样时核对原服务／入口片段仍与原PRG相同，检查栈恢复与无缺ROM／不支持指令／非法控制状态。

29组参考覆盖六种完整声音word、恢复／开／关、四种初始化标志、槽0／1／3／255和关闭状态下直接调用服务。参考保存在`tmp/map-sound-native/`。纯C17组完整128KiB RAM和17组实际播放参数对照、29组生产运行时请求及25组World请求条件／开关顺序检查已通过。初始化标志0的外层控制器和设置后的模式／初始化标志写入未计为World API全状态对照。

独立原加载快照核对三组地图目录与当前NPE一致。SDL检查三段候选PCM首帧在段请求／范围请求之间一致、缓存改写、实时槽更新、完整word条件、打开／关闭、槽255及错误范围。

41目标构建无警告，40项必要短检查全部通过；前批1644份证据与原文件／字库保持。构建、短检查及哈希汇总见`tmp/run_map_sound_checks.py`和`tmp/map-sound-report.json`。首轮构建的十六进制token错误与首轮探针误把回调放在参数6而非参数10的失败日志保留。
