# 入图坐标字节回绕与零尺寸地图装载（2026-10-09）

## 原版依据与C实现

原换图函数48:21E0的前26字节将两个输入word的低字节复制到栈参数首字节；48:2290..23B2随后计算视口。参数提升后与宽／高比较，写入四个坐标时截断成字节，没有小地图钳制，也没有坐标必须落在网格内的判断。

- X+8小于宽：X<7时偏移0、屏幕X为X，否则偏移X-7、屏幕X为7。
- 其它X：偏移为宽-15的低字节，屏幕X为X减去已回绕偏移的低字节。
- Y+2小于高：Y<4时偏移0、屏幕Y为Y，否则偏移Y-4、屏幕Y为4。
- 其它Y：偏移为高-7的低字节，屏幕Y为Y减去已回绕偏移再减1的低字节。

`npe_map_spawn_viewport`已按此实现。零宽度、X=0会得到偏移241、屏幕X15；这是原函数结果，不补写一个正常尺寸或替代坐标。资源解析`npe_map`也允许零宽／高，仍按实际EOF检查17字节文件头和网格长度。
