# 地图四状态、装备状态重建与 V15 存档

更新：2026-10-06。本轮运行时仍为纯 C11 + SDL2，原厂 WASM 仅离线取证。
以下规则从原 PRG 与独立原厂按键采样还原，字段和效果读取当前 NPE。

## 地图类型 2

原厂 `30:9494..955E` 装载仙术四状态，`30:9F16..A102` 执行类型 2。
地图记录四字为 `6A04/6A06/6A08/6A0A`，与战斗 `648E..6494` 分开。
顺序对应 NPE 字节 `31/33/29/35`，沿用已核对的中毒／眠／封／第四状态次序。

- 单体将四项效果分别加到目标原字，保留低 16 位；不取最大值、不夹零、不按说明推测免疫。
- 重复施放叠加，正值与负值都执行；倒地目标也能施放状态术。
- 此分支直接返回，不调用装备状态重建；费用随后从施法者气扣除。
- 当前 NPE 的“唯心唯灵”（ID 40）四项效果均为 +3，费用 16；实现不按 ID 判断。

### 群体分支的原厂别名写入

`37:D280..D298` 的群体地图调用传入目标 **-1**。
`30:9FEA..A102` 对三个活动标志逐个检查，却用外层队员索引同时选状态字与效果，
内层四次重复相加。地址 `6A04 - 148 + 2*i` 落在背包 `67C8 + 2*(212+i)`。
因此这条分支修改数量字 212～214，第四效果不参与；队员四状态不变。
C 版保留该固件行为，没有改成猜测的全队免疫。

该游戏没有对应的友方群体状态术。为验证服务，将独立原厂实例中**已装载的**仙术群体字
设为 1、四效果设为 `[7,-5,11,-13]`，实际按 Confirm：

| 活动标志 | 原厂数量字 212～215 | 原厂角色四状态 |
| --- | --- | --- |
| 1/1/1，第二人倒地 | 28 / 65516 / 44 / 0 | 三人均保持原值 |
| 1/0/1 | 28 / 0 / 44 / 0 | 三人均保持原值 |

内存变化采样还确认了实际写入位置，不只核对角色面板。
这是隔离服务夹具，不计入剧情通关，不修改源 NPE、PRG 或连续剧情档。

## 装备正状态重建

`39:1974..20A2` 按原槽位顺序 `0,3,1,2,4,5` 重读当前装备。
每件装备的四状态中，**有符号大于零**的字覆盖对应地图状态；零／负值不清除原状态。
重建没有先清零；更换装备时，旧装备留下的状态可能继续保留。
已有 C 装备／卸装 API 已接入这一步。

独立原厂实例仅布置装备库存与初始状态 `[1,2,3,4]`，实际用物品→装备菜单：

| 操作 | 原厂四状态 | 原厂攻击／防御 |
| --- | --- | --- |
| 装备神农避毒珠 85 | 5 / 2 / 3 / 4 | 42 / 40 |
| 同槽换为山海经 91 | 5 / 2 / 3 / 5 | 80 / 78 |
| 另穿女娲鳞甲 26 | 5 / 2 / 3 / 5 | 86 / 133 |

C 对照同时检查体／气、攻防、六槽装备、三项背包数量和四状态，三阶段一致。
本轮没有独立核对卸装界面的原厂按键、不同正值装备的覆盖先后及负状态装备夹具；
固定扫描顺序与正值判断来自 PRG。装备体／气、其他属性的完整增减与回绕仍待完成。

## 存档

`NpeWorld.status_guard` 扩为三人各四字。新格式 `NPESAV15` 保留 V14 全部原字段偏移，
仅在末尾追加三个角色的第四状态字，共六字节。

- V15 写读保存四状态，包括负值低字和群体服务造成的背包字变化。
- V1～V14 仍可读；前三状态和其他字段照旧，缺失的第四状态补零。
- 保留游戏指纹、长度及校验和；缺少新增尾部的伪 V15 拒绝，目标世界不被改写。
- 旧 V13／V12 夹具转换已先移除 V15 尾部，地形异常检查偏移也随之调整。

## 验证与边界

- 七种原厂状态序列，12 个施法阶段、**28 个队员状态**及背包别名一致：
  重复、回绕、三人单体、倒地目标、四项正负效果、群体别名、停用队员。
- 三个原厂实际换装阶段一致。
- 新增两项生产 SDL 按键场景：状态术和倒地目标状态术；地图施法 SDL 累计 **9 场景**。
- 全量构建、ctest **5/5**、地图施法／裁剪／提示回归、V15 与 V14 兼容通过。
- 连续 C 主线仍以 **20 份角色属性诊断档**到 173、告别、标题；花胶 15 份、425 次往返。
  此连续路线没有手改敌人、地图、NPC、库存、条件、进度或 NPE。
- 本轮没有新增整屏像素样本；累计已验收整屏仍为 **203 张**。

剩余：地图多人使用／装备临时窗口、装备完整属性、地图状态道具、全部状态页与提示、
战斗负值／复合效果、逐行动动画、正常属性 SDL 全程、声音及跨游戏验收。
状态字段扩展不等于这些模块已完成。
