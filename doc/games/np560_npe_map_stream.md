# 地图文件流边界与天明V1.3（2026-10-09）

## 实现变化

`npe_map`原来把相邻目录项之间的字节数同时作为网格和事件表读取上限。原目录定位函数31:76BE与地图装载函数0C:BDBE没有把下一条目录偏移传给文件读取服务。C现改为以当前NPE的实际文件末尾限制读取，并按头部声明的数量计算事件表实际长度：地形变化组逐项读取数量和索引／图号对，其余组沿用已还原的固定记录长度。

没有按游戏名修补偏移、修改资源或跳过失败地图。没有新增存档字段；World绑定3554字节及NPESAV22保持。
