# 地图道具使用：原厂规则与多人输入

更新于 2026-10-06。生产实现为纯 C + SDL；名称、图标、肖像及效果读取当前 NPE。
地图使用路径已删除英文桌面选择和结果窗口。战斗使用保留其独立的预扣、执行及复活规则。

## 原厂操作

| 状态或输入 | 原厂结果及本轮实现 |
| --- | --- |
| 物品→使用 | 进入模式 4 背包，按有符号正数量扫描 |
| 单体友方物品确认 | 直接进入第一名队员的目标详情，没有另一个选人框 |
| 目标页上／下 | 循环切换在队队员；一人保持原位 |
| 目标页左／右 | 忽略 |
| 目标页确认 | 应用效果、扣一件、留页刷新；倒地队员也可选择 |
| 数量耗尽 | 冻结当前队员及确认；F4 仍可返回 |
| 群体友方物品确认 | 从列表直接执行，再扫描库存；不打开目标页 |
| 目标页 F4 | 重扫背包，耗尽项消失 |
| 列表 F4 | 回地图模式 1 |
| 类型 ≥25 | 原文“该道具只能装备!”；等待最多两秒，可由按键结束 |
| 非友方物品 | 原文“该道具只能对敌人使用!”；等待最多两秒，可由按键结束 |

数量从固定位置显示前两个十进制字符；真实数量 100 显示“10”，使用后为 99。
体力、气力和属性按有符号低字显示；左列值只绘制前九字符。
例如 32800/32767 在原厂显示为 `-32736/32`。状态按四字的正负拼接毒／眠／乱／封，
负值显示在“状态”，无负值显示“正常”，正值显示在“免疫”。

## 按当前 NPE 执行的规则

地图调用源为 `2F:15C4..19E0`，效果服务为 `30:9444`。
物品类型、群体、阵营分别来自原记录 `+12/+36/+37`。
以下普通道具群体字段任意非零走群体分支；阵营必须等于 1。类型 24 在此前独立分派。

- **类型 1：** 体／气相加后截成 16 位，只按有符号上限比较，不做下限夹取。
  三项其他属性 `+21/+23/+25` 同样累加低字；攻防 `+17/+19` 在此地图分支不变。
  群体包含倒地的在队成员。没有重新装载装备状态。
- **类型 2 单体：** 四状态各自相加，重复使用会叠加，允许负值和回绕。
  状态原字段顺序为 `+29/+31/+27/+33`。龙眼的眠值是加 5，不是取最大值。
- **类型 2 群体：** 保留原厂错误：传入目标 -1，成员索引同时作状态索引，
  每个在队成员的效果重复四次写入背包 212～214 的别名字，而非队员状态。
  独立非连续队列夹具证明中间不在队成员不写入。
- **其他友方类型 <24：** 共用地图服务没有对应效果，调用者仍消耗数量。
  已独立实测类型 16／19；佛光舍利在地图上不恢复体力。
  这更正了此前根据道具说明在地图上直接复活全队的实现。
- **类型 24：** 使用独立地图任务道具表及剧情门槛，后续已通用实现。
  顺序匹配、扣件、原拒绝提示及清屏对白续接见[任务道具证据](np560_npe_map_quest_items.md)。

没有通过道具名字或固定游戏 ID 分派以上生产规则。

## 独立参考与验证

`tmp/map-native-use-menu.mjs` 恢复原厂地图快照，复制主角记录构造一／二／三人队伍，
设置状态和背包；变体只修改 WASM 中的 NPE 驻留副本。
磁盘 NPE／PRG 和连续剧情均不改。复制记录用于确定人数、写入对象和输入规则，
不代表其他真实角色的肖像和页面已独立验收。

- **17 组原厂夹具：** 单体恢复、单体状态、原群体物品、一／二人循环，
  正值跨符号、负值回绕、四状态混合回绕、群体恢复、群体其他属性、
  群体状态／不在队跳过、类型 16、敌方拒绝、数量 100、装备／类型 31 拒绝。
- `map_use_native.h` 由原厂 JSON 生成两次使用的完整队员属性及四状态、库存和别名字。
  新 `sdl-map-item-flow-probe` 对照这 **28 个使用阶段**。
- 有效队列的 **26 个阶段**测试实际 C 存读，复制出地图模式及不同角色 ID，
  保留被测数值和背包。原厂画面夹具的重复角色 ID 不符合 C 存档约束；
  中间不在队的独立夹具也不符合紧凑队列约束，未将其计入存读。
- **44 张不同参考路径的 240×120 整屏零差异**；累计已验收 **267 张**。
  包括列表、单体目标、符号／四状态、数量边界和三种拒绝页。
  拒绝页在 SDL 流程中重复核对不重复计数。
- **15 组实际 SDL 输入流程通过：** 五组人数／状态／群体／耗尽，七组数值及数量变体，
  三组拒绝页；此前忽略按键结论已由定时提示修订，当前支持提前结束。
- 连续 C 主线仍以 **20 份角色属性诊断档**到进度 173、告别和标题；
  材料 15 份／424 次往返。构建、ctest 5/5 及相关回归通过。
