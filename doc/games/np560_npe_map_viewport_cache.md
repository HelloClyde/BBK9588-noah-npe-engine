# NPE原105-word视口缓存

## 原函数

原CPU2F:E15A..E27E，PRG文件0x2CE15A..0x2CE280（物理4C:E15A），整函数0x126字节，LINK4并保存R0..R7，末尾恢复／返回。诊断在每例运行前核对整个执行区间逐字节保持；没有文件／堆／LCD服务适配，也没有替换函数主体。

从52:7A2C／7A2E读取Y／X偏移byte，52:7A56读取宽度byte。位置取`uint16(X+Y*width)`，固定循环105项；每15项按实时X／width及递增word行号重新计算位置。当前位置按有符号16位扩展、乘2后加实时52:797E地图缓冲指针，读取word再写52:70B4+2*i。循环内位置word递增回绕。没有地图宽度／高度边界检查，零宽度继续读取105项；源与目标重叠时逐项复制，不能换成memcpy或快照复制。

纯C实现为`npe-sdl/map_viewport_cache.inc`的`npe_map_viewport_cache_refresh`；运行时入口`npe_rpg_runtime_viewport_refresh`使用当前RAM／地址映射。缺少运行时或地址不可用返回-2，未宣称该诊断错误等同原异常投递。

## 验证

`reference_map_viewport_cache.py`建立20组独立诊断输入，RAM初始word按不同模式填充；快照确认写入值后才执行原函数。覆盖宽0／1／14／15／25／128／255，偏移0／7／128／241／243／255，Y0／4／8／127／128／251／255，16位符号边界与回绕，以及同址／前移／后移／跨行重叠。

`map_viewport_cache_probe.c`比较每例完整128KiB RAM，核对105次缓存写入；同20组经过生产运行时得到相同RAM，游标与文件读取计数不变。原返回位置、无缺ROM／未支持指令／非法控制流和栈指针恢复通过。初始调试写入一次超过4096字节，被工具拒绝；改为4096字节一块，原执行函数保持。

8目标构建无警告，5项短检查为地图基础、SDL地形变化、视口、出口、农夫路线。上批21组地形装载完整RAM及读取顺序、140进度1／1280运行时保持。此批未修改地图资源解析规则，18份NPE／1379地图扫描结果沿用上批，未把旧扫描计为新运行证明。
