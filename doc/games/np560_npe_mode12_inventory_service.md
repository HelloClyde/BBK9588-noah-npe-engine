# NPE 模式 12 的背包服务

分派器 `4A:F552` 调用运行时 `27:5A68`，升级包对应 source
`44:5A68..5DAE`。事件号限于 1..5，减一后索引 RAM
`52:76B0` 的 8 字节记录。地图装载函数 `29:ED2C..EE8A`
逐字段填充这张表，地图尾部索引第 13 组的记录布局为：

```
BE16 数量 | u8 增加标志 | BE16 物品编号 | u8 后续模式 | BE16 后续事件
```

背包数组从 `52:67C8` 开始，按一基物品编号乘二寻址。增加分支执行
16 位加法；减少分支先执行 16 位减法，再在有符号结果为负时清零。
两个分支都将记录中的后续模式和事件号交回分派器。文字提示与约
2 秒等待暂未复刻。
