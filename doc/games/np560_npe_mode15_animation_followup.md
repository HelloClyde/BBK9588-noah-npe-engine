# NPE 模式 15 场景动画与后续事件

更新：2026-10-06。结尾 SDL 实测先发现记录字段偏移错误，
随后原厂运行时比较确认资源段也取错。以下结论包含两次修正。

## 文件记录与固件装载

第 1 组每条 13 字节。source `29:D59A..D8A2` 依次跳过两字节记录号，
读取组号和标记、四个单字节坐标、绘制／清除方式及后续模式／事件。
模式 15 的 `4A:36A4..3764` 将 RAM `7550` 的组号送给
runtime `24:ACBA`（source `41:ACBA`）。

| 文件偏移 | 含义 | RAM |
| --- | --- | --- |
| +0..1 | 大端记录号，装载时略过 | — |
| +2 | 一基动画组号 | 7550 |
| +3 | 保留标记，本调用未使用 | 7551 |
| +4／+5 | 单字节 X／Y，零扩展到字 | 7556／7558 |
| +6／+7 | 第二组坐标，本动画服务未使用 | 755A／755C |
| +8／+9 | 绘制／清除方式 | 7552／7553 |
| +10 | 后续模式 | 7554 |
| +11..12 | 大端后续事件号 | 754E |

旧文所述“小端坐标 (60,60)”不成立：地图 73 的原记录
`000102003c003c000201050032` 实际是第 2 组、(60,0)、
绘制 2／清除 1、后续 5／50。地图 107 的
`000100013c003c0002000e0002` 组号为 0；
原服务 `41:ACCA..ACF8` 拒绝零组号，调用者
`4A:3764..37DC` 忽略返回值，仍接 14／2。
C/SDL 现同样跳过绘制并继续事件，不替换动画资源。

## 资源段修正

场景动画目录／图像在 NPE 第 13／14 段（零基段号），角色动画在
第 6／7 段，不能共用同一组号查找。source `31:EF96..EFE2`
将场景段指针装入 RAM `79F6`／`79FA`；原厂运行时此次实测的指针
分别为 `00197F04`／`00198470`，与当前 NPE 的第 13／14 段起点一致。
《天降风云 V1.3》有 100 个场景动画目录项，前三组分别为
62／12／37 帧，其余为空，总计 111 帧。
C 解析器新增独立的 `npe_scene_animation_frames/frame`，
保留 `npe_animation_frames/frame` 给第 6／7 段的角色动画。

## 当前结尾验证

天机阁地图 18 的记录为 `00010300000000000000150000`：
第 3 组、(0,0)、绘制 0／清除 0、后续 21／0。
NPC 184 的告别对白接故事 200～203，故事 203 接 15／1。
`sdl-ending-flow-probe` 使用独立进度 173 夹具，以真实 SDL 按键分页，
实际读取第 3 组全部 37 帧 240×120 图像，随后回到 NPE 标题，
没有调用桌面弹窗。连续 C 世界回放也从原末战／传送／存读档走到该链。
此前“三帧 40×40”的结果来自错误的角色动画资源，已撤销。

原厂参考使用 OpenNOAH `GameRuntime` 的 `certified_original_v1`，
运行相同 PRG；启动新游戏后，用独立内存夹具设置进度 173，并通过原生
模式 16 装载地图 18 的 (12,9)，随后真实按键上走、与 NPC 184 交谈和分页。
这是一段隔离原厂参考，不能算原始属性全程通关。
从故事 203 结束前开始捕获显示提交，前 37 次提交与场景第 3 组
0～36 帧的 28,800 个索引像素逐字节一致，含原资源的重复帧；
随后两次提交为转场／标题。

SDL 探针检查实际 `SDL_UpdateTexture` 上传的数据，在合成以后将
LCD RGB 还原为索引像素，以原厂提交的独立 FNV-1a64 基线核对每帧。
37 帧、原告别分页、模式 21→7 及无桌面弹窗均通过。
基线位于 `npe-sdl/tests/ending_native_frames.h`；它不依赖 WASM 运行。
这里核对的是索引像素，SDL 的近似绿色 LCD 色阶没有作为物理 LCD 验收。

原厂此次也由故事 203→模式 15→标题，没有调用故事 204／205。
扫描本文件全部 147 张地图、249 个 NPC 分支头和 217 个故事控制记录，
没有找到指向故事 204 的后续；故事 204 自身指向 205。
结尾场景图像已包含“陆孤梵带着柳紫仪……”等叙事文字，
不能因未调用故事 204 就在引擎里硬接额外文字。未证明其它版本的行为。
