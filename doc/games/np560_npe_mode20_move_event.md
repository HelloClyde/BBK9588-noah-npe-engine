# NPE 模式 20：按编号转入地图移动事件

更新：2026-10-10。生产服务现读取原十槽驻留表，低字节编号、无效模式0及入口地图初始化已补齐；空槽只清位置，其余字段保持。原参考与旧自身档兼容详见[行走驻留事件](np560_npe_walk_trigger_resident.md)。以下直接从文件取字段的说明为早期实现记录，不再描述当前服务。

分派器 source `4A:F592` 调用 runtime `30:AC04`，升级包对应
source `4D:AC04..ACEC`。函数接受事件号低8位为1..10，减一后按 10
字节步长读取当前地图已装载到 `52:7490` 的移动事件表。它把
`+8` 的模式字节写入当前模式，把 `+0` 的字写入当前事件号。

地图装载 source `29:EE94..F096` 从地图尾部索引第 14 组
每条 11 字节记录中跳过前两字节，分别填充 RAM 表的
`+6/+8/+0/+2/+4` 字段。因此 C 版可直接从文件记录
`+4` 读后续模式、`+5..6` 读后续事件。这个服务不检查
记录所对应的地图坐标或剧情进度；这些条件用于正常走路时
触发事件。

地图 1 的第 1 条移动事件保存 `(5,1)`；C 版真实资源探针
已验证模式 20 会将其作为下一步。当前尚未定位《天降风云》
剧情中进入模式 20 的实际路径。
