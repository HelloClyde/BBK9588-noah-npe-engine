原厂分派表 source `4A:F512` 调用 runtime `32:43F6`，升级包中的
候选源码入口为 `4F:43F6..446A`。该函数在 `52:7936` 为 2 时
使用一套界面函数，其余事件号使用另一套；两套都根据 `52:7AB4`
决定先初始化界面还是处理按键。此前推断地图 1 的模式 18 事件 1 结束后
进入 `(模式 4, 事件 3)`，但在线原版实际进入 `(模式 5, 事件 3)`；
该路径是救援剧情，不是属性界面。本节其余模式 4 观察来自独立菜单入口。

后一套按键处理入口 source `4C:6FBA..70F8` 对输入码
`0x82/0x83/0x84/0x85/0x80/0x81/0x86/0x8E` 分别分派。
其中 `0x8E` 调用 runtime `32:1E6E`，对应 source
`4F:1E6E..1EF0`。当界面状态 `52:7A4A` 为 1 时，该函数
将 `52:7934` 模式设为 1，并将 `52:7AB4` 设为 1；它不改
`52:7936` 事件号。界面初始化 source `3F:B4BA` 将
`52:7A4A` 设为 1。

C/SDL 版现允许在模式 4 用 Backspace 或 F4 返回地图，保留事件号；
属性页已用当前 NPE 的底图和肖像、原厂字库绘制，《天降风云》首位角色
的留存原机整屏帧已逐像素核对。此前确认键额外弹出英文 SDL 角色摘要，
这不是该原机画面，现已移除。原厂 `0x86` 分支在 source
`4C:70B8..70E0` 调用 resident `1F:49E2`。进一步从升级包对应的 source `3C:49E2..4A50` 反汇编可见：界面状态 `52:7A4A=1` 且 `52:7A4C>=1` 时，调用将状态设为 2、清零 `52:7A0C`、把 `52:7A48` 设为 1，再调用 source `49:567C` 绘制下一层。留存的原机输入序列确认这一步从“状态／穿戴”子菜单进入角色属性页。C/SDL 已按此顺序接通；属性页再次确认的原机结果仍未捕获，不把旧英文弹窗当作已复刻操作。
