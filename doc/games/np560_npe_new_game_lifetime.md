# 新游戏构造与驻留状态（2026-10-07）

## 本轮修正

- 冷构造先清零整个 C 运行状态，再装载当前 NPE；剧情进度先设为 1，地图变化随后按该进度应用，避免读取旧栈内容。
- 标题页“新游戏”和空槽开始游戏使用独立的运行中构造入口 `npe_world_restart_game`。重置 RPG 数据，从当前 NPE 重载角色、地图及初始朝向、视口；保留本轮原厂对照确认的事件号、事件/NPC 上下文、菜单/穿戴/说明、商店、出口、音乐、随机及 LCD 背景状态。
- 队伍事件缓存沿用地图装载规则：覆盖 NPE 中存在的前项，保留未提供的槽位。商店种类 `7A0E` 独立建模并保留；C 的目录活动标记失效，下一次商店入口重新装载。
- 标题入口不再重新设随机种子或重新抽音乐。音乐开启时停止旧曲并恢复驻留音乐槽；关闭时不发出新请求。音乐设置以运行状态中的标记为准，移除 SDL 控制器的重复副本。
- 标题两种构造入口补齐构造提交、标题调用方的重复提交及后续地图初始化，共三次 SDL 提交；加载画面采用原装载时的对象绘制顺序。
- `NPESAV15` 不增加驻留字段，原 NPE/PRG 不改写。原 PRG/WASM 仅用于离线取证；C/SDL 程序不依赖它们运行。
