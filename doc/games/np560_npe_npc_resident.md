# NPC 驻留记录与地图服务共享

2026-10-08。实现文件为 `npe-sdl/resident_npcs.inc`，冻结证据为 `tmp/npc-resident-report.json`。

## 本轮实现

`52:6CA2..6DB9` 的20个NPC槽共280字节，现在由World持有，资源运行时按同一地址读取、改写。此前只有坐标和方向覆盖，图号、ID、有效进度和移动标志仍直接读取NPE。

| 驻留偏移 | 字段 | NPE记录偏移 |
| --- | --- | --- |
| 0～1 | ID，大端字 | 0～1 |
| 2～3 | 图号，大端字 | 4～5 |
| 4～5 | 开始进度，大端字 | 8～9 |
| 6～7 | 结束进度，大端字 | 10～11 |
| 8 | 方向字节 | 6 |
| 9、10 | X、Y字节 | 2、3 |
| 11 | 移动标志 | 7 |
| 12 | 对话上下文字节 | 12 |
| 13 | 装载器保留的槽尾字节 | 无 |

原装载器每槽重写前13字节，并保留字节13，连空NPC槽也遵循这条规则。C地图装载、暖读档和标题重新开始采用同样布局与保留行为。NPC绘图、巡走、碰撞、交谈选择、脚本移动和走路叠画改为读取World驻留记录的派生视图；C移动的现有坐标／方向覆盖也投影到客机RAM读回值。

字节级、非对齐和跨槽读写均可用，坐标255是真实字节值。World整段写入先校验范围；被拒绝的越界写入不部分修改NPC状态。总绑定字节由2132增为2412，其它未知RAM仍归资源运行时保存。

NPC元数据是换图时重新装载的临时记录，自身存档仍用NPESAV22。冷读档从NPE构建记录，既有诊断坐标恢复规则保持；运行中读档重载NPC元数据和位置，并保留活槽尾字节。原机存档互通已取消，本轮未实现原机存档格式。
