# NPE 物件拾取：库存、地图地形、提示和存档

更新：2026-10-08。已取消的正常属性完整通关和 SDL 全程实玩不恢复。

## 固件顺序与本轮修正

原 PRG 的 source `37:141E..1620` 对应运行地址 `1A:141E..1620`。拾取服务按以下顺序执行：

| 顺序 | 原服务／位置 | C 行为 |
| --- | --- | --- |
| 1 | `29:CE22` 选择器；`37:1486..148C` 检查标志 | 用实际视口前方坐标选择物件；已有任意非零标志直接返回 |
| 2 | `37:14F0`；`25:3082`，source `42:31FA..3284` | 标记已取，把对应工作网格字写成 53 |
| 3 | `2F:E15A`、`2F:6AB8` | 按地图装载绘制顺序提交改后的地图；此时库存尚未增加 |
| 4 | `37:156A..15BC` | 按有符号 16 位数与 99 比较；小于 99 才加一，按字回绕 |
| 5 | `22:C370`，source `3F:C370..C854` | 按道具编号低字节读取当前 NPE 名称；名称最多 12 字节，说明从另一个地址开始 |
| 6 | `37:15CC..161A`；`03:4050` | “得到 ”＋名称，5000ms 或按键结束，恢复底图 |

`33:6E0A` 在 PRG source `50:6E0A`，按逻辑字节顺序为 `B5 C3 B5 BD 20 00`。提示没有引号、数量或说明。原 `739E` 名称后的 `73AA` 强制 NUL；说明单独从 `73AB` 开始。

撤掉了旧 C 的“名称换行说明”对白页、65535 拒绝和超过 99 继续增加。库存达到上限仍会把物件标记已取并替换地形；65535 视为 -1，拾取后为 0。无目标、重复拾取和方向大于 3 保留已有画面。

地图批量恢复 `source 29:C13E` 调用 `25:3082(1,-1)`，它只清除标志恰好为 1 的物件；随后 `29:C14C` 调用地形服务。C 将拾取地形和剧情地形放入同一个有序稀疏工作网格，后续写入覆盖先前值，资源文件不修改。

## 原执行证据的范围

[`reference_object_pickup.py`](../../npe-sdl/tests/reference_object_pickup.py) 在 QEMU 中执行未修改的原选择器、控制器分支和地形写入服务。入口是明确的诊断跳转，绕过键盘送达；所有 RAM 初值由客体指令写入，宿主不写客体 RAM。

12 条路径涵盖库存 0、98、99、100、32767、32768、65534、65535，已有标志 1／2，方向 4／255。库存、标志、地形字均通过；八条拾取的边界调用顺序为地图准备、地图提交、道具加载、复制前缀、追加名称、5000ms 提示。前两个边界观察旧库存，道具加载开始观察新库存。

地图绘制、道具文件 IO、字符串复制和提示本身是明确的记录边界。因此这份证据**不证明原键盘送达、原拾取画面或物理时间**。历史原机《英雄传奇》真实 M53／0x86 拾取证据保留在 [世界状态与选择器](np560_npe_world_state_and_action_selector.md)；它也不能替代本轮当前游戏的逐提交画面对照。

原报告：`tmp/object-pickup-native/report.json`。原提取：`tmp/object-service-original-source.asm` 与 `tmp/facing-direction-original-source.asm`。

## 实际 C／SDL 验证

[`sdl_object_pickup_probe.c`](../../npe-sdl/tests/sdl_object_pickup_probe.c) 通过实际 `main.c` 主循环和 SDL 渲染器执行上述 12 条路径：八条拾取共 24 次提交，四条不拾取零次。每条再按一次 Return 验证不重复拾取、不额外提交。方向 4／255 从已有可绘制地图面进入诊断状态，不将 255 的冷资源索引失败计为已修复。

提示叠层由独立 Python 根据原前缀、当前 NPE 名称、原字体及 source `3E:FE26..FF86` 的几何构造，检查 SDL 读回像素、背景保留与恢复。这是**源码支持的提示检查，不是原拾取帧零差异声明**。整幅地图尚无本轮原拾取逐提交参考。

另以实际服务函数验证 5000ms 等待跨 SDL 计数器回绕（三次提交），实际主循环验证提示中关闭窗口（两次提交，不恢复、不继续输入）。主循环中的 12 条路径均用按键立即关闭提示，以隔离原 4 秒 NPC 定时器；超时后 NPC／追击交错没有据此验收。

诊断探针最初重建世界时清掉了主循环已绑定的动画回调，造成额外绘图；修正为保留宿主回调。先前以文件名推测“超时周期”的失败日志不足以证明原因，最终只采用修正后的数据。库存更新后恢复底图的保留状态也已补齐。失败日志保留。

## NPESAV19

运行时最多需要 45 个剧情地形格和 8 个物件格，容量改为 53。V19 保留 V18 全部字段位置，在末尾追加八对索引／地形字，共 32 字节；保存为 V19，读取 V1～V18。
