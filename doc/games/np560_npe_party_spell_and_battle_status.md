# 角色攻击仙术与入战状态分区

更新：2026-10-06。依据原厂 NP560.PRG 反汇编及原厂运行时隔离按键采样。
这些参考采样只用于验证 C 规则；独立游戏程序仍只使用 C11 和 SDL2。

## 角色攻击仙术的体力效果

源 `2D:3CA6..43F8` 处理角色行动 1。NPE 仙术 `+14` 是逻辑类型，
`+37` 是群体标记，`+38` 是作用阵营；不能拿 `+12` 的动画类型代替它们。
当逻辑类型为 1、作用于对方时，`2D:3DD6..3E3A` 计算：

```text
effect = signed16(NPE 体力效果 + signed16(当前战斗攻击) / 3)
if effect <= 0: effect = 12
```

除法向零截断，加法保留低 16 位。这一步没有敌方防御减项或伤害浮动。
现有普通行动队列仍在实际施法前取两次准备随机数，轮到角色时扣气。
C 的 `npe_battle_party_spell_damage` 已实现此步骤，并用于现有单体纯体力攻击仙术。
随后已接入 NPE 群体伤害／治疗／增益／状态，见[后续验证](np560_npe_group_spells_and_native_list.md)。
其余复合效果、完整攻防增益计时及当前战斗属性的所有边界尚未完成。

原厂隔离参考从相同的新入战快照恢复，在两个独立进程中仅改变主角属性：
等级 3、体力／上限 30000、速度 999，当前攻击分别为 60、120。
随后实际按左、确认、确认、确认，选择原 NPE 仙术 4（剑气决）。

| 当前攻击 | NPE 体力效果 | 执行效果 | 原厂敌方体力变化 | 主角气变化 |
| --- | --- | --- | --- | --- |
| 60 | 60 | 80 | 500 → 420 | 60 → 50 |
| 120 | 60 | 100 | 500 → 400 | 60 → 50 |

原厂 RAM 字序现已修正：正确读取是大端的高字节及低字节。旧采样把低字节与相邻字段组合，
将原始 500 错读成 244；这一差异结论撤销。独立进程重新采样确认 500 → 420／400。
真实 NPE 的 C 隔离探针对应验证 500 → 420／400、气 60 → 50 及准确随机状态。
函数边界探针覆盖有符号除法、16 位回绕和非正效果回退。

## 地图状态与战斗状态独立

源 `38:E110..E146` 对每个参战角色清零战斗记录的六个状态字
`648E..6498`，其中前四个是状态，后两个是攻防计时。
源 `39:188E` 使用的是地图角色记录的 `6A04`，会按传入效果和装备更新地图状态；
它没有把这些字复制到战斗 `648E`。

在原厂隔离参考中，将主角战斗前四字设置为 `[-2,3,-4,5]`，
重新触发模式 3 初始化后六字全部为零。
另一独立采样同时设置地图四字为 `[7,-8,9,-10]`：
入战后地图四字原样保留，战斗六字仍全部为零。
NPE 和敌方数据均未改写；这些设置只属于原厂规则夹具，不属于连续剧情证据。

C 使用独立的 `battle_party_status[3][4]` 和地图 `status_guard[3][4]`。
三个入战入口清零战斗六字，再按当前 NPE 装备重建地图正状态；
敌方仙术、行动判断、中毒和状态推进均使用战斗区。
胜利清除状态后回写地图，成功逃跑／战败将当前状态直接回写地图。
NPESAV15 保存地图四字，并兼容旧档。

**2026-10-06 更正：** 旧原厂采样只覆盖无装备入战。
此前“胜利、逃跑和败战都清除战斗状态、不改地图区”的结论撤销；
旧 C 离场断言并未对照原厂。本轮以八组独立原厂按键夹具及复制／重置源码修正，
详见[入战与离场证据](np560_npe_battle_state_lifecycle.md)。
