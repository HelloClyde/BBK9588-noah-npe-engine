# 装备目标页保留重绘与槽位顺序（2026-10-08）

本轮修正纯C11＋SDL2生产程序的装备目标页。NPE、PRG和原快照保持原文件；离线原WASM只生成对照，不是生产运行依赖。原机存档互通、正常属性完整通关和SDL全程实玩继续取消。

## 原代码与生产实现

装备属性使用的格式串运行地址`30:5962`映射至PRG物理`4D:5962`，交换词内字节后为`%d`。负数参考另独立验证。此前装备目标页把武器、鞋子、披挂对应槽读错；穿戴页原有顺序已正确，本轮修正目标页。

每次换人只覆盖数量、头像、六个装备名称及七个右侧值栏。小头像之外的旧LCD保留；大头像可以覆盖标签、图标或道具名称。道具名称在初次绘制时读共享缓存，随后装备逐行加载仍保持原缓存生命周期，不在页面末尾再次重画名称。重复装备同一件时，原流程不提交LCD；探针对该阶段的零提交和人物／库存／缓存状态均进行检查。

## 地图选帧核对

原`46:BD0A..BE8A`在行走分支将本地计数初始化为0，循环至4，取计数模3；结束后静止绘图取方向×3＋中间帧。两处均读取69D4朝向，不读取69D3。`tmp/character-map-frame-source-full.asm`保存对应反汇编；既有`character-map-frame-source.asm`另含相关调用。

NPE字节77被装入69D3，不等于这两个入口使用它选图。C现有静止中间帧／行走模3规则保持；不把字节77接入绘图。69D3的完整驻留／别名保存、其它消费者、其它姿态及异常朝向组合仍需核对，本轮不是完整148字节记录验收。
