# 复活仙术、脚本战免疫与中毒调用门槛

更新：2026-10-06。实现位于纯 C11 + SDL2 的 `npe-sdl/`；原厂运行时仅用于隔离采样，不是 C 程序运行依赖。

## 原始资源与复活分派

《天降风云 V1.3》NPE SHA256：
`df4b52df6b69e1105a5ea6100e43f35f832ed859c10cb8714879e44ad4d8cb40`。
PRG SHA256：`d555609e03ece17f42c1881beeb88361572f18621161de67bc9dc765857089f5`。

原仙术 1“回魂咒”的文件 `+14` 为类型 19、`+37` 单体、`+38` 自方，费用 80。
C 依类型和目标标记处理，不以名称或编号特判；名称、说明与费用仍取当前 NPE。

`3A:09E8..0A2C` 把载入的逻辑类型写到行动记录 `64D0/64D2`。
`40:1562..15AA` 对类型 16～19 跳过通常的倒下目标重选。
`2A:0C4C..0F4A` 是实际体力提交；不能把动画／提示页的数字计算当成结算公式。

| 类型 | 原厂体力提交 |
| --- | --- |
| 16 | 上限乘 10，乘积低 16 位作有符号数，再除以 100 |
| 17 | 上限乘 30，同样截低字、有符号除以 100 |
| 18 | 上限乘 50，同样截低字、有符号除以 100 |
| 19 | 直接写入体力上限 |

`2A:0E88` 为 `MUL R6,R0`，`0E8E` 的指令字节为 `01 C2`，是只读有符号 R7 的 16 位 `DIV R1`。
所以类型 18、上限 999 的结果不是通常百分比的 499：低字 49950 当作 −15586，除以 100 得 −155，体力字为 65381。
C 保留这一回绕，未自行夹值或加“至少 1 体”。类型 19 不经过该乘除。

只有体力有符号值不大于零的在队记录会被修改。
单体保留预选记录；群体遍历紧凑队伍，不延伸到敌人。
复活提交不清四状态、不恢复气、不清攻防增益或行动标志。
在收集指令时已倒下的队员不会补做本轮行动，下一轮恢复指令资格。
若另一个队员先复活了同一目标，后续已排队的复活仍扣费，但跳过存活目标，不改选。

## 原厂独立采样

脚本：`tmp/battle-native-group-spell.mjs`，每个进程只恢复一次原厂快照。
RAM 字为高字节在 `a(offset)-1`、低字节在 `a(offset)`。

`1 revive2` 是**隔离规则夹具**：移动完整原敌方记录，复制一条原角色战斗记录，提供第二名倒下目标；设置角色属性及已学前缀。
它不是角色属性诊断的连续剧情存档，也不证明两人原版站位的绘制。
未改变 NPE、PRG 或敌方记录内容。

| 原厂时刻 | 结果 |
| --- | --- |
| tick 599 | 原战斗目标选择状态 27；目标体力 0，施法者气 999 |
| tick 625 | 气 999→919 |
| tick 689 | 倒下目标体力 0→30000 |
| tick 756 | 敌人原普通攻击使复活目标 30000→29957 |
| tick 761 | 下一轮复活者行动标志恢复可选 |

单人、无人倒下的原仙术 1 确认后保持列表，不扣气。
双人夹具用下键切到倒下记录；原目标页是战斗画面上的箭头，不是地图属性页。

`1 revive16`／`1 revive18` 是额外的**强制分派夹具**：上限 999，只把已排队的类型字改为 16／18。
两次在 tick 689 分别得到 99／65381、气 919，验证原 PRG 的截字除法。
这些值来自运行时类型替换，不能描述为原 NPE 自带这两项复活术。
日志为 `tmp/battle-native-group-spell-1-revive2.json`、`-revive16.json`、`-revive18.json`。

## 敌方中间槽的眠免疫

`31:D718..D75C` 在入战编组后，无条件把 `party_count+1` 物理记录的 `6490` 写成 10。
它对应敌方槽 1；一名敌人的编组中，该槽是未使用记录，不能把槽 0 改成免疫。
因此野猪编组 `0/51/0` 的眠 +10 是固件赋值，既不是敌人 NPE 默认字段，也不是所有敌人都免疫。
三个 C 入战入口现保留这一规则。

`38:FEA2..FEF2` 在每轮状态更新后，仅当脚本标志 `7A9A==1` 时再次给中间槽写 10。
这解释了原采样“鬼魅乱舞”之后的眠 10→9→10。
C 对脚本战刷新，普通遇敌不做每轮刷新；其它正免疫仍保持，不自行按回合递减。

## 中毒结算调用门槛

前轮 C 实现每轮无条件调用中毒，已修正。
源 `39:5936..5A30` 在每次选行动者前，把倒下、眠或封为负的记录标成不能行动。
`39:605C` 在实际行动提交后调用 `36:6FBC`；后者 `6FFE..708C` 要求所有记录的 `64E2` 标志已置位。
若行动之后剩余记录才被前置扫描标成不能行动，且没有后续实际行动，就不再调用毒伤。
完全没有实际行动的轮次同样不扣毒伤。

原仙术 30 单人对野猪的采样：tick 619 毒／封／第四状态为 −2、眠为 9，敌人体力仍 500；
tick 684 剩余行动标志置位；tick 686 状态 −2→−1、眠回到 10，体力仍 500。
C 规则探针现核对该结果。前轮隔离测试中的 500→302 是无条件毒伤造成的错误，撤销。

共享毒伤公式不变：角色中毒先取敌方首槽等级两倍，首槽等级零时取槽 1；
存在存活中毒敌人时，再以紧凑队伍首条记录的等级两倍覆写，同一个最终值作用于两侧。
C 把紧凑首记录映射为第一名在队角色，不再误用固定逻辑角色槽 0。
