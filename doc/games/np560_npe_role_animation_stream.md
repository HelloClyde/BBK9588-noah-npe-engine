# NPE 角色／战斗动画顺序装载与移动

更新：2026-10-08。当前纯 C11＋SDL2 实现接入角色动画第6／7段的运行时装载、缓冲生命周期及移动计算。整体仍粗估约80%，并未完成所有固件服务或所有 NPE 的适配。

## 原函数与实现

- 原物理 `3C:43D4..49E0`，运行时 CODE `1F:43D4..49E0`：角色动画装载和播放。
- 原物理 `4E:8756..8802`，CODE `31:8756..8802`：保存／恢复画面的选项、三种绘图及显示提交。
- 原物理 `49:75D6..77C6`，CODE `2C:75D6..77C6`：两个坐标的取整。
- CODE `32:BCA6`：有符号16位数转浮点；`2F:52B4`：除法；`2F:45E4`：乘法。常量来自 DATA `5F:2A44` 的0与 `5F:2A4C` 的0.5；DS为32KiB银行，不能把银行号当成物理高16位。

`animation_stream.inc` 共用场景和角色的装载骨架，分别读取当前 NPE 初始化的 `52:79F6/79FA` 和 `52:79DE/79E2`。组号的乘5减5保留有符号16位回绕；清零后分别读取4＋1字节组信息、首帧4＋4字节偏移与长度。组为空或偏移非法时保留原返回值。

资源只分配、锁定和定位一次；分配量为首帧长度加1的低16位，读取量为首帧长度的低16位。多帧分支连续读取，每次复用同一客机缓冲，后续帧描述符不再参与播放。结束、绘制失败、关闭窗口和文件释放均清理捕获的局部句柄。

生产主程序的逃跑、角色施法、角色仙术效果、敌方仙术效果及合击五个播放点使用这条管线。人物动画组号来自当前角色记录，仙术效果组号来自当前技能记录，数据仍取当前 NPE。

## 单帧与移动细节

先以16位回绕计算 `dx=startX-endX`、`dy=startY-endY`。

- 多帧：步数等于组中的帧数，每帧读取一次载荷。
- 单帧：步数为有符号 `max(dx,dy)/16`，不取绝对值。载荷只读一次，即使步数小于等于0。
- 每次以字节计数1开始，用浮点斜率乘当前计数，调用原取整规则，再从原始起点减去偏移。同一点的单帧动画没有显示提交。
- 计数保留字节回绕；步数达到255时原循环可能持续运行。C保留这个分支，并允许宿主关闭窗口后清理缓冲；尚未做该异常循环的独立原函数动态验收。

原取整先把浮点提升至双精度，减0.5后转整数，再与原值直接转整数的低16位比较；相等且原值大于0时加1。不能用普通 `roundf` 代替，例如正的小偏移会直接得到1。

原除法 `2F:52FE..530E` 读取被除数高字并右移7时，没有屏蔽符号位，负被除数会使指数越界，进入 `53A6` 的负无穷返回分支。独立函数采样得到：

| 运算 | 原返回位型 |
|---|---|
| 有符号整数−7转float | `C0E00000` |
| 有符号整数7转float | `40E00000` |
| −7.0÷3.0 | `FF800000`，负无穷 |
| 7.0÷3.0 | `40155555` |

C保留此行为；浮点转整数的原指数范围检查使这类非有限偏移返回0。因此反向移动分支可能保持起点，不能自行改成普通负斜率插值。

## 独立参考与验证

`tests/reference_role_animation_runtime.py` 在原QEMU上执行未改写的角色函数、软浮点、取整、堆与真实绘图代码。适配边界为文件IO、失败提示、LCD选项／提交和等待；没有捕获堆头预置。源载荷在运行前逐字节核对，暂存地址跳过原启动与角色函数所在银行。

最终报告为 `tmp/role-animation-runtime-native-v2/report.json`，共62例：29例通用／战斗位图、13例场景动画及20例角色动画。

| 角色测试范围 | 原显示帧数 |
|---|---:|
| 角色施法、逃跑、合击 | 16 |
| 奇数横坐标模式1／2 | 6 |
| 正向、反向、半数与小数偏移 | 15 |
| 单帧正向与正负混合距离 | 8 |
| 单帧同点、反向、距离不足16 | 0 |
| 组号0／负值／空组、目录EOF／两字节短读 | 0 |
| 载荷EOF | 3 |
| 合计 | 48 |

两种绑定各跑一次，共40条路径、96次实际SDL绘制。每帧比较完整131072字节客机RAM、28800个索引像素、SDL RGBA像素、绘制坐标、文件游标、读取次数与失败次数；结束后比较40份完整RAM、最终像素及原返回值。单帧零步数分支仍核对那一次载荷读取。两种绑定使用零初始化的独立世界，不能代表完整游戏启动状态。

新角色段指针初始化下，场景回归13例／26路径／342次完整RAM与SDL绘制一致，通用与战斗资源回归29例／58路径一致，实际资源查看器入口16提交通过。

生产短路径回归：

- 合击18次，280次动画提交，309人物记录阶段及18次最终SDL画面。

最终主程序及7个探针共8目标构建无警告，7项短检查退出0。五项原始资源哈希保持，自身存档仍使用 `NPESAV22`。

旧合击探针只拦截 `new_game`，当前标题使用 `restart_game`；开场等待也超过旧线程的5秒期限。探针已接当前入口，并按既有非计时菜单探针方式供应帧等待输入，仍完整绘制开场、实际输入合击菜单和逐帧核对合击。失败线程也发送退出，旧挂起进程已终止。首次并行构建受该测试进程的Windows文件锁阻挡；终止后重建通过，失败构建日志保留。
