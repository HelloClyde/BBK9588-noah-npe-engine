# 共享技能记录与学技提示（2026-10-08）

生产程序为纯 C11＋SDL2。技能名称和属性来自当前NPE；原PRG／参考WASM仅用于离线核对。本轮实现共享装载器，接入模式9学技的实际SDL提示和数字服务；地图仙术与战斗菜单等其它调用点仍待按原顺序接入。

## 原装载器

原源码 `3F:23C4..28D8`（运行时 `22:23C4`）使用编号字节 `7A74` 和 `730E..739D` 的144字节记录，与道具的 `7A72/739E` 独立。

- 参数取低字节。编号0每次清零全部144字节；同一非零编号直接返回旧缓存。
- 换编号用当前NPE第3段的一基偏移表寻址，没有记录总数检查；名称读12字节，再强制写缓存字节12为0。
- 文件说明从偏移41开始，写缓存偏移13起最多101字节，遇0结束；终止符后的旧字节保持。
- 缓存字节119（原 `7385`）没有字段读入，换编号也保留。不能将尾部固定字段按连续文件布局直接复制到缓存。
- `npe_world_skill` 返回的名称／说明和派生原始字段指向同一个世界的共享缓冲，下次装载会覆盖。`skill_record_raw[42]` 是现有属性接口所需的派生视图，不是另一份原固件记录。
- 原 `46:D110` 新游戏仅将7A74置0，**没有清记录字节**；角色装载没有像装备那样再次清技能缓存。暖系统／标题读档及传送保留编号和字节；主机冷解码／构造清零。缓存不写入NPESAV19。

字段位置（字节偏移；字保留大端顺序）：

| NPE字段 | 144字节缓存 |
| --- | --- |
| 0～11名称 | 0～11，12强制0 |
| 12／13／14元数据、等级、效果类型 | 114／115／116 |
| 15／17／19／21体力、气及两属性 | 120／122／124／126 |
| 23／25／27三个字 | 130／132／134 |
| 29／31／33／35四字 | 140／136／138／142 |
| 37群体、38阵营 | 117、118 |
| 39费用 | 128 |
| 41起说明 | 13起，最多101字节 |
| 无对应文件字段 | 119保持 |

资源预览 `npe_skill` 继续使用严格记录解码；新增 `npe_native_skill` 和 `npe_skill_record` 供原运行装载使用，接受空名称及未在记录目录内结束的文本。宿主EOF边界仍检查，未模拟原失败IO时的全部部分写入或任意RAM别名。

## 实际学技服务

模式9先插入18字节技能区，再共享装载该技能，按原 `40:A24E..A2D0` 显示 `修炼成"技能名"`。同编号旧名称直接沿用；技能0清空记录且显示空名称，未改学习插入规则。恢复底图后才执行原后续模式／编号。

纯资源预览提示接口保留；实际 `show_skill_event` 使用有世界状态的提示接口。数字 `npe_world_apply_skill_event` 也调用装载，以保留该服务的缓存副作用。
