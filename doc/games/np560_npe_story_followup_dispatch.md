# 对白后续进入模式14的显示调度

2026-10-07。生产实现仍为 C11＋SDL2，故事、NPC对白及剧情事件均读取当前 NPE。

## 修复

此前 `npe_world_finish_story`、`npe_world_finish_mode2` 及其它后续调用者直接执行模式14，先写进度，再返回 SDL 调度。调度看不到模式14，因而漏掉原服务更新进度之前的地图提交，返回地图时也可能漏掉保留音乐槽的重播。

现在 SDL 的单轮输入和事件链设置运行期 `defer_story_events`：这些调用者只写模式14及完整事件字，交回显示调度。调度设置原7AB4请求、提交旧进度地图，然后调用 `npe_world_execute_story_event` 执行事件。回模式1时继续既有音乐重播、清7AB4及新进度地图提交。无显示的数字接口默认仍立即执行事件。

该宿主字段没有原RAM地址，不进入NPESAV17，也不参与保留画面的状态比较。初次对照发现退出显示范围时它会引发多余提交，已经修复；其它世界字段仍按原有方式比较。显示调度的提前返回由外层函数恢复范围，下一轮输入前也会清除它。
