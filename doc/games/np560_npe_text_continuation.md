# NPC 对白、故事后续及共享控制缓存

更新：2026-10-07。生产实现仍为纯 C11＋SDL2，读取当前 NPE 的对白和故事资源。

## 原版依据

- 故事入口 `43:6796..67E0` 从故事记录读一字节模式到 `52:7A0A`、两字节事件号到 `52:7A82`。
- 故事关闭 `43:6956..698C` 请求地图初始化，随后从这两个驻留字段恢复模式／事件；不重新读取 NPE 控制字段。
- NPC 对白关闭 `3B:7728..7748` 使用同一对驻留字段。
- 调度器 `4A:F498/F4A0` 把小于1或大于24的模式送至 `F5EE`，写模式1并请求地图初始化，保留完整事件字。
- 这两个驻留控制字段不在原版游戏存档内；原系统保存／读档、标题读档、暖新游戏、空槽新游戏四条 UI 路径，都保留诊断设置的模式25／事件65535。

源码摘录：`tmp/text-control-original-source.asm`、`tmp/story-entry-map-init-original-source.asm`。原 UI 驻留采样：`tmp/native-text-control-resident.json`。

## 修复

1. NPC／故事关闭统一恢复原始后续。SDL 先保留非法模式，随后由实际调度器回地图；数字接口包含这一步归一化。非法模式不再被当成不支持的故事而卡在文本里。
2. `npe_world_prepare_story` 在进入故事时装载共享后续字段，`finish_story` 关闭时使用缓存。没有准备显示页的数字调用仍按需读取记录。测试在准备后修改内存里的资源控制字段，证明本次关闭读旧缓存、下一次入口读新资源。
3. 暖新游戏和暖读档保留共享模式／事件字；宿主文本活动标志重建。冷构造／冷主机解码不恢复这些驻留字段。它们仍不序列化，线格式保持 `NPESAV17`。
4. 移除 `show_walk_story` 按 NPE 故事记录总数限制续接次数的代码。循环故事可以继续等待确认，也可以响应主机关闭。

## 验证范围

### 非法后续

原 NPC1普通文本、NPC24→全屏故事20、NPC25→窗口故事28三条路径，各使用音乐关／开，共六条。音乐关组在等待文本时诊断设置共享模式0，音乐开组设置255，事件号都设置65535。修改原参考运行时的驻留控制字段；NPE 资源及字符串保持原样。

六条共 **46次实际 `main.c`／SDL 提交**，索引像素和 SDL ARGB 读回均零差异；最终模式1／事件65535、进度、250个 NPC 状态字节、玩家／视口／方向、20个 NPC 位置、保留曲槽的重播位置和 SDL 声音游标匹配。原参考的 RAM 状态是每次 `advance` 结束状态，不能视为每个显示提交的逐指令快照。

当前 NPE 的217条故事记录没有模式0或大于24的后续。本组证明诊断输入下的固件关闭／调度行为，不宣称当前游戏自然存在这类故事记录。C 另覆盖模式25及 NPC／故事数字和显示接口两种策略。

### 循环故事

原 NPC24入口进入故事20后，在驻留缓存中设置后续5／20。原240次 `advance` 的短片段始终停留模式5／事件20／进度25；包含三幅 NPC 文本、一幅故事入口地图和 **七幅相同故事页**。这是非终止片段，没有将它计作完成流程。

C 直接调用生产 `show_walk_story`，完成 **220次故事重新进入、221幅页面提交**，每幅 C 索引和实际 SDL 读回均与上述原重复故事页一致。第221页注入 `SDL_QUIT`，确认没有执行这页的后续，退出服务并重新提交关闭事件。此检查超过文件的217条记录，能发现旧上限；没有宣称原版已采样220次循环，也没有宣称物理输入时序一致。

### 构造、存档及回归

- 原四条 UI 采样与 C 暖恢复／暖新游戏的共享字段终态匹配；C 冷主机解码清零，准备失败不改世界，NPC 入口覆盖故事活动标志。
- 修改共享控制字、事件字和文本活动标志，保存后的字节与基线完全相同，文件头仍为 `NPESAV17`。
- 八个定向目标构建成功且无警告；两个新探针及五个既有相关短探针，共七项最终退出0。记录见 `tmp/text-control-regressions.json` 和 `tmp/text-control-report.json`。
- 原 NPE／PRG SHA256 保持。没有重跑正常属性完整通关、SDL从头到尾实玩或长综合路线。

## 仍未完成

通用事件调度仍有64次链限制；其它模式交错、完整图形平面和驻留状态、原冷启动、真实输入时基／RNG、PCM／增益及其它 NPE 适配继续。这里的证据仅证明列出的文本续接、缓存及循环行为，整个引擎尚未验收完成。
