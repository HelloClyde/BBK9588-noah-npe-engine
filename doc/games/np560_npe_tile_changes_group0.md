更新：2026-10-05。按原始 NP560.PRG 的地图装载和模式 14 进度服务实现；主线牢房开门、C 图像／通行及 SDL 按键已验证。原机动态画面及逐帧时序仍未验收。

## 原文件记录

17 组地图目录的第 0 组是可变长度记录，最多 3 条；每条为：

| 字节 | 内容 |
| --- | --- |
| +0..1 | BE16 剧情进度下限 |
| +2 | 格数，最多 15 |
| +3 起 | 每格 BE16 网格索引、BE16 替换地形编号，4 字节 |

网格索引为 `Y * map.width + X`，并非图像编号或事件号。解析验证完整长度、3／15 容量和网格边界；宿主拒绝原厂有符号索引的负值范围，避免越界。原 NPE 和静态网格字节不变，运行时建立稀疏地形视图。

## 固件行为

装载 source `29:D24E..D456` 读取进度字、数量字节及成对的索引／地形。展开到 `52:724E + 64*slot`：阈值在 +0，15 个索引在 +2..31，15 个地形在 +32..61，应用标记在 +62。

`29:D36C..D43E` 在当前进度无符号大于等于阈值时，把每个已声明的地形写入地图工作网格（指针 `52:797E/7980`），依文件顺序应用；这里允许索引 0，也允许阈值 0。`29:D47A..D490` 把应用标记初始化为 0。

模式 14 source `4C:4CE2` 写进度；`4C:4CEA..4CF4` 随后以类型 2 调用 runtime `25:3082`，对应 source `42:3082`。其中 `42:328A..346A`：

1. 遍历 3 槽，阈值非零、当前进度达到阈值、应用标记为 0 时更新。
2. 最多读 15 个索引，**有符号索引小于等于 0 即结束本条写入**。这与装载阶段的索引 0 行为不同，C 实现保留区别。
3. 写入后标记为 1，调用地图绘制服务；已应用的记录不会因随后进度降低而撤销，也不会重复覆盖后应用的另一条记录。

C 在地图装载／换图／传送重建记录，在原进度事件更新时执行一次性写入；行走入口也处理尚未应用的有效阈值。通行与世界绘图共用稀疏运行时网格。加载和实时更新的区别、非升序阈值覆盖、回退仍保持已应用地形均有探针。

## 牢房主线与 SDL

原进度 115 进入地图 108 (12,16)，两格牢门是不可通行地形 196。走到 (4,13) 朝上触发原故事 206“咯………”；故事完成接进度事件 1，进度到 116，两格替换为地形 10。角色按原地图行走到 (12,5)，面对 NPC 112，原故事／队伍后续到 118，赵梦雪重新入队。

`sdl-tile-change-flow-probe` 用隔离的真实 NPE 地图状态发送标题确认、开关移动、原对白确认和 16 步方向键，实际穿过 (12,8) 到 (12,5)，没有桌面弹窗。独立 C 渲染检查两格开门后的全部 512 个像素等于当前 NPE 地形 10 位图，且原始网格仍为 196。这证明 C 的资源渲染和通行一致；没有声称与原机该节点整屏像素已对齐。

## C 存档 V14

当前格式 `NPESAV14` 在 V13 追击状态之后固定增加 182 字节：一字节应用掩码、一字节格数、45 组小端索引／地形字。保存最终网格值，支持不同阈值先后写同一格的状态；不保存 NPE 指针或 C 结构填充。

读取验证掩码、容量、索引去重以及索引／地形对来自当前地图 NPE。V1～V13 没有动态网格字段，按当前地图和已保存进度重建；V13 的追击状态继续保留，V1～V12 仍按原地图初始化追击。原厂存档互通未实现。
