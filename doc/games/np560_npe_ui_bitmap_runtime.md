# NPE 菜单位图资源接入

更新：2026-10-08。纯 C11＋SDL2 将菜单、人物肖像及战后提示的部分绘制接入已有客机 RAM／堆／文件读取／原绘图管线。整体仍粗估约80%，未完成全部固件服务或所有 NPE 的适配。

## 原函数与资源选择

`tmp/ui-bitmap-source.asm` 来自未修改的 NP560.PRG。原物理 `31:EA3A..EA64` 初始化 `52:7AF8` 和 `52:7AEC`，分别来自当前 NPE 头的第6、7个图组基址。运行时通过这两个驻留字加组内序号，保留16位回绕。

原音乐弹窗 `4F:1FFA` 使用 UI组＋6；属性页 `3D:8D38` 使用 UI组＋18，肖像使用人物组基址；穿戴页 `38:1238` 使用 UI组＋10，选择框 `38:170E` 使用 UI组＋11及透明模式2。原父菜单和系统子菜单也从 UI组驻留字取资源。

新 `npe_image_group_index` 在运行时附着后读取驻留字，避免用当前文件的位图总数倒推UI起点。`npe_render_indexed_resource` 调用原通用索引装载服务的C实现；原UI调用者忽略的−1／−3继续忽略，适配器失败仍返回失败。无运行时的资源查看保留元数据绘制。

已接入标题、故事／答题背景、金额栏、父菜单及属性／物品／系统／音乐弹窗、存档槽背景、属性页和穿戴页背景／肖像、装备图标和透明选择框、商店图标／数量框、仙术选人弹窗、战后掉落／学技／升级背景。资源和图组来自所打开的NPE，字体与固件固定提示保持原来源。
