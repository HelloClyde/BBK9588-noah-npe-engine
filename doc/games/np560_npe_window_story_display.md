# 原版窗口剧情显示

日期：2026-10-06。生产程序直接读取当前 NPE，用 C11／SDL2 绘制；原厂运行时只用于诊断采样。

## 原始指令与行为

模式 5 读取故事记录 raw3 的样式。样式 1 使用 NPE 整屏背景；本项补齐样式 0 的底部窗口。

- `43:6842..688E` 设置窗口 `(0,84)..(240,118)`，没有按文本行数扩展面板。
- `3F:9170..91BA` 只在文本非空时清除该矩形；末行 y119 和上方进入剧情前的 LCD 内容保持不变。
- `3F:8E7A..8EDA` 以原始分隔符读一段，确认后读取下一段；不把它改成整屏样式的每页三段。
- `46:E552..E7CA` 用 8／16 像素宽的原厂字体，LF 为一个空白 ASCII 单元；按 GBK 边界换行。下一行字体底边超过窗口底部时停止绘字，故事读指针仍继续原段之后。
- `43:6928..6956` 仅接受原厂推进键，其它键不会关闭窗口。

代码原先重画地图、按文本行数调整窗口、把 LF 当换行；现在保留进入剧情前的屏幕，在固定区域用当前 NPE 原文绘字。不新增对白、标点、翻页标记或桌面结果窗口。整屏样式继续使用当前 NPE 的背景资源与原文。

## 独立采样与验证

采样故事 1、3、6、11、51、87、149、195，共八段、**54 页**。包含短对白、混合 ASCII／中文、LF 空白、长段、多页及原文件最长的窗口故事。每段从原厂已有 LCD 状态进入，只改变独立诊断 RAM 的模式／事件编号；原 NPE、PRG 和连续主线存档均未编辑。

纯 C 和实际 SDL 每页均与原厂完整 240×120 像素一致，共 54 张不同窗口页面。SDL 通过 Enter／Space／小键盘确认推进，Left／F4 保持等待；结束后 C 读取原记录后续模式与事件，原模式 14 通过地图事件表处理。未把原厂继续执行后续地图事件后的状态与单步 C 接口中间态混为同一阶段。

测试先在 SDL 显示采样的进入前 LCD，再调用实际生产剧情函数；这些图只属于独立参考夹具，生产程序不加载它们。此项验证窗口绘字与屏幕保留，没有把这些背景当作地图生成的独立验收。

此前整屏剧情 23 页 C／SDL 继续通过；两类剧情共 **77 页、77 张不同页面**，与静态 334 张、战斗动画 2119 次／723 张分别统计。
