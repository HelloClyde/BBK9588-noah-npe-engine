# 诺亚舟-NPE-引擎 v0.1.4（预发布）

修正走路动画的等待和提交顺序。按原NP560固件64Hz公共时基，将等待参数10毫秒换算为至少一个tick，等待到期后提交姿态；移除每个姿态固定67毫秒的网页节奏。四姿态0、1、2、0及随后的一格位移/地图滚动保持原版行为。

新增不依赖游戏资源的SDL行走计时测试，覆盖公共时基相位、等待前不提交、普通输入消费、关闭窗口、零等待及32位时钟回绕。七项自动测试通过；天降风云十条行走路径的42次原版提交在C、SDL及实际主程序方向键入口全部零像素差异。Windows Release重新构建并生成便携包。

详细原固件逻辑见 `doc/games/np560_npe_walk_display.md`。主机时基换算及模拟器验证不代表真机恒定帧率；跨游戏完整兼容仍在完善。自身三槽存档格式未变。
