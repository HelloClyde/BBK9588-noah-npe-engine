# 诺亚舟-NPE-引擎

这是开发版。核心游戏功能已有实现；音频以流畅播放为目标，完整跨游戏兼容仍在完善。

## 启动

解压整个目录，保留 `assets` 和程序的相对位置。Windows 下可以把 `.npe`
文件拖到 `npe-sdl.exe` 上；也可以直接双击 EXE，在弹出的文件选择框中打开 NPE。
取消选择会直接退出。也可以在 PowerShell 中运行：

```powershell
& '.\npe-sdl.exe' 'D:\游戏\天降风云V1.3.npe'
```

标题、人物、剧情、地图和游戏资源由传入的 NPE 读取。程序需要自己的字体
文件和随包提供的 SDL2 运行库；运行时不需要 PRG 固件、DMCU 模拟器或 Python。
NPE 游戏文件由使用者提供，不包含在此包内。

也可以跳过标题直接开始，或读取第 1 槽的自身存档：

```powershell
& '.\npe-sdl.exe' --new-game 'D:\游戏\天降风云V1.3.npe'
& '.\npe-sdl.exe' --continue 'D:\游戏\天降风云V1.3.npe'
```

## 窗口菜单

Windows窗口顶部提供“文件”和“关于”。“文件→打开NPE”可选择并切换游戏，“文件→退出”关闭程序；“关于”显示项目名称和作者HelloClyde。

## 常用操作

| 场景 | 操作 |
| --- | --- |
| 移动和列表选择 | 方向键；I／J／L／M 对应上／左／右／下 |
| 标题和菜单确认 | K 或 Enter |
| 地图上与 NPC 对话 | 空格 |
| 地图上对物件执行动作 | K 或 Enter |
| 对白和剧情翻页 | 空格；剧情文字页忽略 Enter |
| 地图上打开菜单 | F4 或 Esc |
| 菜单返回 | F4；部分页面也接受 Esc／Backspace |
| 战斗 | 从四图标选择攻击、仙术、道具；旗帜菜单选择防御／逃跑 |
| 穿戴页 | J／L 或左右键选槽，U 卸装，N／P 翻说明 |
| 动画播放 | 方向键、Enter、空格、F4／Esc 提前结束当前帧等待；退格和字母键忽略 |
| 答题 | 按画面中的 A／B／C／D 作答 |

不同页面按原版分派处理按键。标题、系统、存读档、音乐和道具／仙术确认页
忽略空格；部分 NPC 对白另有 K／Enter 结束入口。

## 手柄

支持 SDL2 能识别的标准游戏控制器，一次使用一个手柄，可在运行中插拔。
按 Xbox 布局标记：

| 按键 | 操作 |
| --- | --- |
| 左摇杆／十字键 | 移动、菜单选择；按住可连续操作 |
| A | 确认；对白／剧情中翻页 |
| X | 与NPC对话、空格翻页 |
| B | 返回、地图打开菜单 |
| Start | 打开手柄按键说明；Start／B关闭 |
| Y | 穿戴页卸装 |
| LB／RB | 说明上一页／下一页 |
| 答题时 A／B／X／Y | 分别输入答案 A／B／C／D |

摇杆有死区；切换到其它窗口或拔出手柄会清除持续方向输入。
未被SDL识别为游戏控制器的设备暂不支持自定义映射。键盘仍可同时使用。

## 存档

从地图菜单选择“系统→存档／读档”，支持三个槽位；标题的“再续前缘”也可读档。
存档按 NPE 内容指纹隔离，保存在 SDL 用户数据目录；Windows 通常为
`%APPDATA%\NPE\npe-sdl\`。移动程序目录或改变工作目录不会改变存档位置。
这是本程序的自身存档格式。

## 文件

- `npe-sdl.exe`：游戏运行程序。
- `SDL2.dll`：本 Windows 构建使用的 SDL2 运行库；其它构建所需 DLL 由打包时自动检查。
- `assets/gbk12-native.bin`、`assets/gbk16-native.bin`：原版位图字形。
- `assets/FONT-PROVENANCE.txt`、`licenses/SDL2-LICENSE.txt`：资源来源和 SDL2 声明。

若字体文件缺失或损坏，程序会停止启动并在控制台报告错误。
